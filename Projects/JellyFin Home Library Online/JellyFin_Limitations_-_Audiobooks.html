JellyFin Limitations - Audiobooks

1000’s of Audiobooks left out in JellyFin Search

Issue:

  • Searches only 1 Level Deep

Clunky Work Around:

  • Search for Keyword in CMD

A Regular JellyFin Search will Show Movie Locations, but leave out Audiobook Infomation, although JellyFin can still be used to Play the Audiobook.  (No Bookmark or Start-At/Left-Off-At Support)

Audiobook Library Search.bat - in - “Send To“

@Echo Off
Echo Audiobook Library Search:
echo.
if not defined Library_Item set /p "Library_Item=Audiobook String Search: "
dir /b /ad /s F:\AUDIOBOOKS | findstr /i %Library_Item%
echo.
pause

REM # Absolute Positioning
REM # Moves the cursor to a specific row and column 
REM # (1-indexed, where 1,1 is the top-left corner).
REM # Format: ESC[<row>;<column>H 
REM # or 
REM # ESC[<row>;<column>f

REM # Examples:
REM # \033[10;20H 
REM # moves the cursor to row 10, column 20.
REM # \033[H (or \033[1;1H) 
REM # moves the cursor to the home position (0, 0).
     
REM # Relative Positioning
REM #      Moves the cursor a given number of cells 
REM #         (\(N\)) from its current location.
REM #       Up: 
REM #         ESC[<N>A
REM #        Down: 
REM #          ESC[<N>B
REM #        Forward (Right): 
REM #          ESC[<N>C
REM #        Backward (Left): 
REM #          ESC[<N>D
REM # Save & Restore
REM #        Saves the current cursor position 
REM #        so you can return to it later.
     
REM #        Save Position: 
REM #          \033[s (or \0337)
     
REM #        Restore Position: 
REM #          \033[u (or \0338)
     
REM # Query Position
REM #        Asks the terminal emulator 
REM #        to report the current cursor position 
REM #        back to standard input.
     
REM #        Report Sequence: 
REM #          \033[6n
     
REM #        Note: When the terminal replies, 
REM #              it sends the response back to your program 
REM #            in the format 
REM #        \033[<row>;<column>R.

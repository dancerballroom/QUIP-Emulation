IMPORTANT NOTE:  
STORY-WISE
       01_of_38_Monsters_Inc.srt/mp4 goes from 00:00:00 to 00:20:17
       02_of_38_Monsters_Inc.srt/mp4 goes from 00:20:00 to 00:40:17
but        
       Part-#.srt/mp4 files go from 00:00:00 to 00:20:17
       (01_of_38_Monsters_Inc, 02_of_38_Monsters_Inc, 03_of_38_Monsters_Inc, etc.)

Each part starts at 00:00:00 and ends at 00:20:17 
                                                                                       
Prompt Variables:
FILE:       "Gullivers Travels.srt"
TOT_LEN:     11:27:50 (in SECONDS)
INC_LEN:     20:17 (With Overlap) (in SECONDS)
INCREMENT:   20    (Split Point)

Main Program:
for %A = 0 to TOT_LEN step Subtitle_INCREMENT
   Count += 1
   Start = %A
   End =   %A + Subtitle_INC_LEN
   Part-File = %Count-of-TOT_LEN-(MOD INC)-FILE.srt
   ffmpeg -i FILE.srt -ss %Start -t %INC -y %Part-File
   ffmpeg -i %Part-File.srt %Part-File.lrc
next

SRT_SPLIT.bat - Version 1.0

@Echo Off
setlocal enableDelayedExpansion
REM Echo Split "%~d1%~p1%~n1%~x1"
REM Using: ffmpeg -ss 00:00:03 -to 00:00:08 -i subtitles.srt -c copy cut.srt
REM Using: ffmpeg -i cut.srt cut.lrc

Echo.
set FILE="%~d1%~p1%~n1%~x1"
set NEW_FILE="01_%~d1%~p1%~n1%~x1"
echo.
set /p TOTLEN=   "Length of Video    -> (00:00:00) :> "
set /p SPLIT=    "Split Point        -> (00:20:00) :> "
set /p OVERLAP=  "Length INC Overlap -> (00:20:17) :> "
set START=00:00:00

echo FILE=!FILE!
echo Video Length=!TOTLEN!
echo Split Point=!SPLIT!
echo OVERLAP=!OVERLAP!
echo.

set CMD1=ffmpeg -ss !START! 
set CMD2= -to !OVERLAP!
set CMD3= -i !FILE! -c copy !NEW_FILE!

echo !CMD1!!CMD2!!CMD3!

pause

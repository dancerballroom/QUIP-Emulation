Helps Subtitle Edit

Function: Turn all Uppercase Subtitles to Lowercase


AutoHotkey v2.0


UCase2LCase-Modified_2026.ahk


  #Requires AutoHotkey v2.0
  ; Control + Shift + E
  ^+e::ToLowercase()
  ; Control + Shift + X
  ^+x::Call_Exit()
 
  ; First Run - Establish Macro
  MsgBox "Setting CTL + SHFT + E, `n(CTL+SHFT+E = ToLowercase - Opened Subedit SRT)"
  ; # Exit Script
  Exit
 
  ; UCase2ULCase.ahk Modified
  ; which in short means
  ; Upper Case to Upper Case and Lower Case Subtitle Conversion ScriptEngine
  ; Auto Hot Key Script for Windows
 
  ; To Use:
  ; 1. Open a .srt Subtitle File to check if all upper case
  ;    if yes, then close.
  ; 2. Double click this file and it takes care of the rest.
 
  ; Create a Shell Object
  ; Open Subtitle Edit
 
  ToLowercase()
- {
      ; Give Subtitle Edit time to load
      Sleep 300
 
      ; Type in Control + Shift + C   
      ; SubtitleEdit Shortcut => Change Casing Screen
      Send "^+C"    
      Sleep 300    ; Command Load Time
        Loop 2
-       {
           Send "{Shift Down}"
           Sleep 300
           Send "+{tab}"
           Send "{Shift Up}"
        }
        Send "{ENTER}"
      Sleep 1000    ; Command Load Time
      ; Verification Screen
        Loop 2
-       {
           Send "{Shift Down}"
           Sleep 300
           Send "+{tab}"
           Send "{Shift Up}"
        }
          Send "{ENTER}"
      Sleep 300  ; Command Load Time
      Send "^s"
      ; Exit Subtitle Edit
      Sleep 1000  ; Command Load Time
      Send "~{F4}"
      Sleep 300  
      ; Yes, Save
      Send "{ENTER}"
  }
 
  Call_Exit()
- {
      MsgBox "Unloading Script..."
      ExitApp
  }

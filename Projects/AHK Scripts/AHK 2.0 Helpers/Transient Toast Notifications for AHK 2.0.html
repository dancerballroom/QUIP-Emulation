Transient TOAST Notifications for AHK 2.0

2. Using Toastify Library (Highly Recommended)
If you want professional-looking, modern toasts with custom themes (dark mode, glass, cyberpunk), animations, and action buttons, the community-created Toastify library for AHK v2 is the standard.
  • GitHub: skeletorflet/AHKv2-Toastification
  • How to use:
    1. Download the library.
    2. Include it at the top of your script: #Include "lib\Toastify.ahk".
    3. Call it like this:

TOP of AHK
#Requires AutoHotkey v2.0
#Include "C:\Program Files\AutoHotkey\v2\lib\Toastify.ahk"

Implementation
1. Simple Toasttify Call
#Requires AutoHotkey v2.0
#Include "C:\Program Files\AutoHotkey\v2\lib\Toastify.ahk"

; Start Toastify (Theme, Alignment)
Toastify.Start("dark", Toastify.ALIGN.BOTTOM_RIGHT)

; Trigger a success message
Toastify.Success("Saved!", "Your changes are safe.")

2. More Complex Toastify Call
#Requires AutoHotkey v2.0
#Include "C:\Program Files\AutoHotkey\v2\lib\Toastify.ahk"

Toastify.Start("dark", Toastify.ALIGN.BOTTOM_RIGHT)
Toastify.Show("Script Set-up Complete", "Control+X = Exit", [ {text: "NotePad++", onClick: (*) => Run("NotePad++.exe")} ])


Other Options:
1.  TrayTip (Simple)
#Requires AutoHotkey v2.0

; Show a toast notification
TrayTip "My Title", "This is the notification message.", 1

; Wait 5 seconds, then hide it
SetTimer () => TrayTip(), -5000
2. Toastify (Complex)

ShowToast(title, message) {
    psCommand := Format("
    (
        [Windows.UI.Notifications.ToastNotificationManager, Windows.UI.Notifications, ContentType = WindowsRuntime] | Out-Null
        $template = [Windows.UI.Notifications.ToastNotificationManager]::GetTemplateContent([Windows.UI.Notifications.ToastTemplateType]::ToastText02)
        $text = $template.SelectNodes('//text')
        $text.Item(0).InnerText = '{}'
        $text.Item(1).InnerText = '{}'
        [Windows.UI.Notifications.ToastNotificationManager]::CreateToastNotifier('AutoHotkey').Show($template)
    )", title, message)
    
    RunWait('powershell -Command "' . psCommand . '"', , "Hide")
}

ShowToast("Success", "Your task is complete!")

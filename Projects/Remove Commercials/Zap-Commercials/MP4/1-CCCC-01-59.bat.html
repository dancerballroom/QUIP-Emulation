CCCC-01-59.bat

Purpose:  Crop .MP4, trim off commercials and Unwanted Extras 

NOTE:  
USES the NAME of the DIR currently IN:  Must be 1-59

Example:
MP4:    Dexter - s04e02 - Remains to Be Seen.MP4

DIR:     C:\Users\Larry\Desktop\My-MENU-GEN\MAX_TEST_02\6

SUBDIR Name is 6
(6 Seconds is removed from the front of the .MP4)
(The Default for 8 Seconds in removed from the end of the MP4)

Output:
MP4:  Dexter - s04e02 - Remains to Be Seen.mp4
SRT:   Dexter - s04e02 - Remains to Be Seen.mp4.eng.srt

CCCC-01-59.bat
@Echo OffSet "ext=mp4"
Set "opts=-v quiet"
Set "opts=%opts% -print_format "compact=print_section=0:nokey=1:escape=csv""
Set "opts=%opts% -show_entries "format=duration""
If Exist *.%ext% (If Not Exist "Trimmed\" MD Trimmed)

For %%a In (*.%ext%) Do Call :Sub "%%~a"
Exit /B
        
:Sub
  For /f "Tokens=1* Delims=." %%a In ('FFProbe %opts% %1') Do (Set /A "ws=%%a-8.0" & Set "ps=%%b")
  rem If %ws% Lss 20 GoTo :EOF
  echo passed 1st FOR
  Set/A hh=ws/(60*60), lo=ws%%(60*60), mm=lo/60, ss=lo%%60
  echo passed SET
  If %hh% Lss 10 Set hh=0%hh%
  If %mm% Lss 10 Set mm=0%mm%
  If %ss% Lss 10 Set ss=0%ss%
  FOR /D %%I IN ("%CD%") DO SET _PARENT_DIR_=%%~nxI

  ECHO PARENT_DIR = %_PARENT_DIR_%
  REM Validate Number 
  SET /A Evaluated=%_PARENT_DIR_%
  REM ECHO Integer
     IF %Evaluated% GTR 0 ( 
        ECHO Positive 
        Echo FFMpeg -itsoffset -%_PARENT_DIR_%.0 -i %1 "Trimmed\%~1.eng.srt"
        Echo FFMpeg -i %1 -ss 00:00:%_PARENT_DIR_% -to %hh%:%mm%:%ss% -c:v copy -c:a copy "Trimmed\%~1"
        FFMpeg -itsoffset -%_PARENT_DIR_%.0 -i %1 "Trimmed\%~1.eng.srt"
        FFMpeg -i %1 -ss 00:00:%_PARENT_DIR_% -to %hh%:%mm%:%ss% -c:v copy -c:a copy "Trimmed\%~1"
    )

    IF %Evaluated% LSS 0 ( 
        ECHO DIRECTORY evaluates to Negative value 
        ECHO =====================================
        ECHO 1.  Create a Directory Name named 1..59
        Echo 2.  Place MP4 in DIRECTORY
        Echo 3.  FILE SendTo CCCC-01-59.bat
    )

    IF %Evaluated% EQU 0 ( 
        ECHO Zero 
        ECHO DIRECTORY evaluates to Zero 
        ECHO ===========================
        ECHO 1.  Create a Directory Name named 1..59
        Echo 2.  Place MP4 in DIRECTORY
        Echo 3.  FILE SendTo CCCC-01-59.bat
        pause
    )        
        REM EOL

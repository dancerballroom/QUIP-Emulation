Part of the Graphical Home Video Library Online Project optimized for Cell Phone Use
Tested Platform:  Windows 10 and 11

000-Standardize-Filenames.bat

@Echo Off
SETLOCAL enabledelayedexpansion

SET /a Seconds=30
:Start_Me
SET CRLF=^


REM Leave the previous two lines Empty

SET MSG="Standardize JPG Filenames!CRLF!!CRLF!
SET MSG=!MSG!A = Two Spaces to One Space!CRLF!
SET MSG=!MSG!B = All Spaces to Dashes!CRLF!
SET MSG=!MSG!C = Two Dashes to One Dash!CRLF!
SET MSG=!MSG!D = Underscore to Space!CRLF!
SET MSG=!MSG!N = Ampersand to AND!CRLF!
SET MSG=!MSG!X = Exit!CRLF!
SET MSG=!MSG!Choose One (A, B, C, D, N, X):!CRLF!
SET MSG=!MSG! : "

CLS
CHOICE /C ABCDNX /N /T 30 /D X /M !MSG!

IF ERRORLEVEL==6 GOTO :ENDER
IF ERRORLEVEL==5 GOTO :FIVE
IF ERRORLEVEL==4 GOTO :FOUR
IF ERRORLEVEL==3 GOTO :THREE
IF ERRORLEVEL==2 GOTO :TWO
IF ERRORLEVEL==1 GOTO :ONE
GOTO END

:FIVE
ECHO YOU HAVE PRESSED N

Set "Pattern=&"
Set "Replace=and"

For %%a in (*.*) Do (
    Set "File=%%~a"
    Ren "%%a" "!File:%Pattern%=%Replace%!"
)

GOTO :SLEEPER

:FOUR
ECHO YOU HAVE PRESSED D

Set "Pattern=_"
Set "Replace= "

For %%a in (*.*) Do (
    Set "File=%%~a"
    Ren "%%a" "!File:%Pattern%=%Replace%!"
)

GOTO :SLEEPER

:THREE
ECHO YOU HAVE PRESSED C
Set "Pattern=--"
Set "Replace=-"

For %%a in (*.*) Do (
    Set "File=%%~a"
    Ren "%%a" "!File:%Pattern%=%Replace%!"
)

GOTO :SLEEPER

:TWO
ECHO YOU HAVE PRESSED B
Set "Pattern= "
Set "Replace=-"

For %%a in (*.*) Do (
    Set "File=%%~a"
    Ren "%%a" "!File:%Pattern%=%Replace%!"
)

GOTO :SLEEPER

:ONE
ECHO YOU HAVE PRESSED A
Set "Pattern=  "
Set "Replace= "

For %%a in (*.*) Do (
    Set "File=%%~a"
    Ren "%%a" "!File:%Pattern%=%Replace%!"
)

GOTO :SLEEPER

:SLEEPER
CALL Powershell -Command "Sleep 3"
GOTO :Start_Me

:ENDER
cls
ECHO YOU HAVE PRESSED X OR REACHED DEFAULT TIMES-UP
SET /a Seconds=!Seconds! - 1
IF "!Seconds!"=="0" (
    Exit
)

ECHO Exiting in !Seconds! Seconds ...
CALL Powershell -Command "Sleep 1"
GOTO :ENDER

Echo Good-Bye!
CALL Powershell -Command "Sleep 3"

Choice Syntax

CHOICE /C ABCDNX /N /T 10 /D X /M !MSG!

* /c <choice1><choice2><…>: 
     Specifies the choices you would like to create, which can include a-z, 
     A-Z, 0-9, and ASCII characters 128-254.
* /t <seconds>: Use this flag to specify how many seconds 
     to wait before the default choice is selected. You can set this value 
     to any number between 0 (which instantly selects the default choice) 
     and 9999.
* /d <choice>: Specifies the default choice from the list of choices 
     created with /c.
* /n (optional): hides the list of choices, but still allows 
     the user to select one.
* /m <text> (optional): displays a message before the choice list. 
   If you do not include this flag but do not hide the choice list, 
   the choices will still be displayed.
* /cs (optional): This specifies that choices are case-sensitive, 
   which is important if you want to assign different functions to capital 
   and lowercase letters.

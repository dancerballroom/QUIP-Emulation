Part 1 - YouTube to Audiobook with Subtitles (.SRT) - 1 Big YouTube AudioBook to 7 - 8hr Audiobooks with Lyrics (.LRC)

Part 1 of 2

  •  Download YouTube .MP4 with ClipGrab (under the more... in the comments section)
  •  Highlight 1st Line of Subtitles + Shift
  •  Click Last Line of Subtitles to Select All
  •  Paste to BOOK.TXT Text File
  •  Run NotePad++ Cntrl+Shift+7 to Prep Standardised Time Format (HH:MM:SS)

    Macro "TRANS2SRT", Format All ##:##:##

  •  Import Transcript into Subtitle Edit
  •  Tools/Break-Split Long Lines/OK/Save As/SRT
  •  Edit SRT with TextPad++/Search "This has been"
  •  Notate All Split Time Sigs

EXAMPLE:

32:30:42
This has been Realms of Time, Scrapyard Ship, Book Four
...
32:31:06
Audible hopes you have enjoyed this program.

-->END Book 4

“32:31:09” 

-->START Book 5

32:31:09
This is Audibe

EXAMPLE Notes:

Notes for The 57 Hour (7 Book) "Scrapyard Ship Series"

Book 1 - 00:00:00 - 08:05:20
Book 2 - 08:05:20 - 16:31:44
Book 3 - 16:31:44 - 24:34:58

Book 6 - 40:38:33 - 49:09:06
Book 7 - 49:09:06 - 57:34:42

Image Sequence to MP4 using FFMPEG

The most common way to convert a series of sequentially named images
 (e.g., image001.jpg, image002.jpg, etc.) into an MP4 video is as follows:

Code:  (All one Line)
ffmpeg -framerate 24 
       -i image%03d.jpg 
       -c:v libx264 
       -pix_fmt yuv420p 
       output.mp4
Explanation of the Command:

  • -framerate 24: Sets the output video's frame rate to 24 frames per second (FPS). Adjust this value to control the speed of the video.
  • -i image%03d.jpg: Specifies the input image sequence.
    • image: The common prefix of your image files.
    • %03d: A format specifier indicating a three-digit sequence number (e.g., 001, 002). Adjust the number of digits (%04d, %05d, etc.) to match your file naming convention.
    • .jpg: The file extension of your images. Change to .png, .jpeg, etc., as needed.
  • -c:v libx264: Specifies the video codec to use, which is H.264 (a widely supported codec for MP4).
  • -pix_fmt yuv420p: Sets the pixel format, which is recommended for broad compatibility with various players and devices.
  • output.mp4: The desired name and format of the output video file.

Handling Non-Sequentially Named Images or Specific Image Sets:

If your images are not sequentially named or you want to include only certain images, you can use a text file listing the images and their durations:

  • Create a text file (e.g., list.txt) with entries like this:
Code:

    file 'image1.jpg'
    duration 5
    file 'image2.jpg'
    duration 3

  • Then, use the following FFmpeg command:
Code:  (All one Line)
    ffmpeg -f concat 
           -i list.txt 
           -c:v libx264 
           -pix_fmt yuv420p 
           output.mp4
Additional Options:
  • -r: Can be used instead of -framerate to set the output frame rate.
  • -crf: Controls the video quality (Constant Rate Factor). Lower values (e.g., 18-23) generally result in higher quality and larger file sizes.
  • -s: Sets the output video resolution (e.g., -s 1920x1080).
  • -loop 1 -t <duration> -i input.jpg output.mp4: To create a video from a single image for a specific duration (e.g., 10 seconds).
Note: Ensure FFmpeg is installed and accessible in your system's PATH. You may need to navigate to the directory containing your images in the terminal or command prompt before running the FFmpeg command.

Creating Japanese/English Subs for Display on Jellyfin Server

Purpose:  Process Videos from Learn Japanese through Story
Story Length:  From 5 to 10 Minutes
  • Download YouTube Video (PlayOn/Potplayer)  TIME: 3-Minutes
  • Place Each MP4 in own DIR (MP4_MKDIR_VID_SUB_BKUP.bat)  TIME: 15 Secs
  • Create Empty Transcript Files (Create Empty YouTube Transcript Files Batchfile)  TIME: 15 Secs
  • Copy ENG Subs from YouTube (more... Show Transcript) into corresponding file.transcript.en.txt.  TIME: 5 Mins
  • Translate.Google.Com: Translate from EN to JP, Save in Transcript File:  TIME 2 Mins
  • Open JP Sub File in SubtitleEdit and SAVE-AS (JP.SRT) TIME 1 Min
  • Open EN Sub File in SubtitleEdit and SAVE-AS (EN.SRT) TIME 1 Min
  • Run Fix English and Japanese AHK Script  ENG-Multi-Line-JP-Time-SIG-Fix.ahk  TIME 1 Min
  • Japanese Script:  Run CNTRL+SHIFT+J (Replace ALL and Fill out XX Template)  TIME 10 Mins.
  • Japanese Script:  Change <SPACE> to <HAT>   FIND "( \d):(\d{+})" TO FIND "(^\d):(\d{+})"  TIME 2 Mins.
  • English Script:  Run CNTRL + SHIFT + E (Replace ALL)  TIME: 1 Min
  • English Script:  Run CNTRL+SHIFT+N (then Manually Fix)  TIME: 5 Mins.
  • Open Each SRT with SubtitleEdit then TOOLS Menu / Fix Numbering  TIME 2 Mins.
  • Once a 1 to 1 Ratio achieved:  TIME 10 Mins.
    • Sub Number/Sub Number
    • Time Sig/Time Sig
    • Line Number/Line Number
    • and NotePad++ has open in Order:  EN-TAB, JP-TAB, Focus on JP
  • Run CNTRL+SHIFT+<PERIOD> one time.  TIME 30 Secs
    • NotePad++ Macros below
  • Run CNTRL+SHIFT+<COMMA> until Files Merged  TIME 2 Mins
    • NotePad++ Macros below
  • Save New.txt  TIME 1 Min
  • Close All open files, Place all transcript and SRT files in Backup  TIME 1 Min
  • Rename New.txt %Movie-Name%.EN.SRT  TIME 1 Min
  • Open SRT with SubtitleEdit  TIME: 20 Mins.
    • Tools/Adjust Durations (Characters/Second)
    • Click Waveform/Adjust the START/END for each SubTitle
    • Save
  • Copy to JellyFin Mounted DIR  TIME: 2 Mins
Total Time (Give or Take: About 1 Hour and 10 Minutes)

NotePad Macros:  CNTRL+SHIFT+<PERIOD> and CNTRL+SHIFT+<COMMA>

Location:  C:\Users\Larry\AppData\Roaming\Notepad++\shortcuts.xml

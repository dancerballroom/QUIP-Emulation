RegEx (Regular Expressions) to aid in the Japanese-English Subtitle Project copy

Purpose: To format multi-lingual subtitles for display on Chromecast’s Client JellyFin.
And it is a fussy one. 

RegEx (Regular Expressions) Explanations Further Below:
# To find Rogue numbers in the Japanese Subtitles:
Find: ( \d):(\d+)
Replace: \r\n\r\nXX\r\n00:$1:$2,000 --> 00:$1:$2,000

# To find Carriage Returns (CRLF) in English Subtitles.  Join.
Find: (^\d+)[\r\n]+(^.*?[\r\n]+.*?)[\r\n.+]+(\D*)$
Replace: $1\r\n$2 $3

# To find Split lines (dd then 5 lines then dd) in SRT
^(\d\d)$\r\n^(.*)$\r\n^(.*)$\r\n^(.*)$\r\n^(.*)$\r\n^(\d\d)$

First half of the Solution

Description:  Formats all entries in subtitle file to be on one line.  This means there will be a 1 to 1 correspondence between the Japanese file and the English file, for example.  
Next:  Save the TEMP.SRT Subtitle file with SubtitleEdit and under Tools run “Renumber” to fix format errors.  Then Run the SRT macro to merge the two languages, fix translation errors, and mount on the Jellyfin Video Server(free)
# To find Rogue numbers in the Japanese files:
Find: ( \d):(\d+)
Replace: \r\n\r\nXX\r\n00:$1:$2,000 --> 00:$1:$2,000

Explanation:
   ( \d) A Space followed by a digit
    :        followed by a colon
   (\d+)    followed by two digits or more

Matches:   
43
00:04:49,000 --> 00:04:51,667
もう私たちは友達だよね？ 4:53
さあ、おいしい柿を食べに一緒に行きましょう。」

Result:
43
00:04:49,000 --> 00:04:51,667
もう私たちは友達だよね？

XX
00: 4:53,000 --> 00: 4:53,000
さあ、おいしい柿を食べに一緒に行きましょう。」

Post (Replace-All) Actions:
1. Locate All XX
2. Replace XX with next Sub Number (here:43)
3. Replace Zero Duration --> 2nd number with calculated second number
   (here:  00: 4:53,000    replaced with    00:04:58,000) 
   (right before the next subtitle comes in)
4. SubtitleEdit: Tools/Renumber/Save
 

# To find Carriage Returns (CRLF) in English Subtitles.  Join.
Find: (^\d+)[\r\n]+(^.*?[\r\n]+.*?)[\r\n.+]+(\D*)$
Replace: $1\r\n$2 $3

# The short explanation
(^\d+)   # The line starts with a Subtitle Number
[\r\n]+  # followed by a carriage return
(^.*?[\r\n]+.*?)   # followed by the time stamp for the subtitle
[\r\n.+]+          # followed by another Carriage return
+(\D*)$            # followed by subtitles - \D* means no decimals
                   # Probably means I have to rethink this because
                   # it won't handle numbers in the subtitles, so
                   # Phooey!
# Replace the above with the same, but control the placement of Carriage Returns.
$1\r\n    # The line starts with a Subtitle Number followed by a Carriage Return
$2        # The next line consists of the time stamp
$3        # The third line is the subtitle line.

Matches:

00:00:27,000 --> 00:00:32,248
When the old woman tried to cut it with a knife, 
the melon split in two on its own.

Result:
5
00:00:27,000 --> 00:00:32,248
When the old woman tried to cut it with a knife, the melon split in two on its own.

Jellyfin server observations:

  • Jellyfin is an odd duck!
  • It does not support standard multiple language formatted files by SubtitleEdit.
  • It requires both Japanese and English to be placed in the English SRT (Movie.EN.SRT) formatted:
    • Time Signature
    • Japanese
    • English

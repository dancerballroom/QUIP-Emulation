PotPlayer No Sound YouTube Work around - Save Video with Audio yt-dlp (formerly YouTube-dl)

1.  The 37-Minute Solution (NOT Optimal)

Problem:  PotPlayer is no longer downloading Videos from YouTube with Audio
Solution:  YT-DLP (YouTube-DownLoadProgram)

  • Download YouTube Subtitles(If available) using PotPlayer
  • Download YouTube Audio using same URL minus the “UBE”, or www.YouT.com
  • Merge the Video using FFMPEG using the format: 
FFMPEG -i VIDEO.mp4 -i AUDIO.mp3 -c copy -VIDEO_merged.mp4
  • DONE

Since it needs to be in the Windows Environmental PATH I just downloaded it to 
C:\FFMPEG\bin, since that directory is already in my ENV Path

USING YT-DLP:

  • Download YouTube Subtitles(If available) using PotPlayer
  • Download the Video with Audio 
    • Syntax:  YT-DLP <URL>
Download a video: Enter the following command in the Terminal or Command Prompt:
  • Type yt-dlp <url_to_video> and press Enter or Return.
    • To paste the video URL, press Ctrl + V
  • This will download the video without subtitles or a description. It automatically chooses the best video and audio quality.

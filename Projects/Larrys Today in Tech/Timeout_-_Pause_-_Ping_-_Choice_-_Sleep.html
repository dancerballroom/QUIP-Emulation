Timeout - Pause - Ping - Choice - Sleep

Timeout

@Echo Off

Echo Wait 30 Seconds
timeout /t 30 /nobreak

Pause

@Echo Off

Echo Wait for the Enter Key
pause

Ping

@Echo Off
Echo Wait for 10000 milliseconds
Echo or 10 Seconds
ping /n 1 /w 10000 localhost >nul

Choice

@Echo Off
SETLOCAL enabledelayedexpansion

SET /a Seconds=6
:Start_Me
SET CRLF=^


SET MSG="N = Hide Choices!CRLF!T = Default in (10) Seconds 0-9999!CRLF!D = Default Choice (X)!CRLF!CS = Case Sensitive (Not used here)!CRLF!M = Message !CRLF!Choose One (A, B, C, D, N, X):!CRLF!!CRLF! -> "
CLS
CHOICE /C ABCDNX /N /T 10 /D X /M !MSG!

IF ERRORLEVEL==6 GOTO :ENDER
IF ERRORLEVEL==5 GOTO :FIVE
IF ERRORLEVEL==4 GOTO :FOUR
IF ERRORLEVEL==3 GOTO :THREE
IF ERRORLEVEL==2 GOTO :TWO
IF ERRORLEVEL==1 GOTO :ONE
GOTO END
:FIVE
ECHO YOU HAVE PRESSED N
GOTO :SLEEPER
:FOUR
ECHO YOU HAVE PRESSED D
GOTO :SLEEPER
:THREE
ECHO YOU HAVE PRESSED C
GOTO :SLEEPER
:TWO
ECHO YOU HAVE PRESSED B
GOTO :SLEEPER
:ONE
ECHO YOU HAVE PRESSED A
GOTO :SLEEPER

:SLEEPER
CALL Powershell -Command "Sleep 3"
GOTO :Start_Me

:ENDER
cls
ECHO YOU HAVE PRESSED X
SET /a Seconds=!Seconds! - 1
IF "!Seconds!"=="0" (
    Exit
)

ECHO Exiting in !Seconds! Seconds ...
CALL Powershell -Command "Sleep 1"
GOTO ENDER
pause
  • /c <choice1><choice2><…>: Specifies the choices you'd like to create, which can include a-z, A-Z, 0-9, and ASCII characters 128-254.
  • /t <seconds>: Use this flag to specify how many seconds to wait before the default choice is selected. You can set this value to any number between 0 (which instantly selects the default choice) and 9999.
  • /d <choice>: Specifies the default choice from the list of choices created with /c.
  • /n (optional): hides the list of choices, but still allows the user to select one.
  • /m <text> (optional): displays a message before the choice list. If you don't include this flag but don't hide the choice list, the choices will still be displayed.
  • /cs (optional): This specifies that choices are case-sensitive, which is important if you want to assign different functions to capital and lowercase letters.

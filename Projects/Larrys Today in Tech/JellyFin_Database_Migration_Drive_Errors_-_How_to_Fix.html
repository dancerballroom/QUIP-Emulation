JellyFin Database Migration Drive Errors - How to Fix 

Problem:  

Although going through Libraries using the JellyFin GUI, deleting old references from OLD to NEW Paths.
ERRORS:  OLD Next-UP and OLD DEAD Links stay Persistent.

NOTE:  We Want the Library Intact.  We just need to Delete the FILE References to the Defunct Hard Drive.

REAL SOLUTION

  • Turn OFF JellyFin Server
  • Add New HDD
  • Copy Offending PATH\Files in “Next Up” and “Continue” to TEMP Drive
    • X:\DIR\SUBDIR\FILENAME.mp4
  • My Computer/Manage/Storage/Disk Management
  • Right Click NEW HDD/Assign OLD Drive Letter  (E: for Example)
    • E:\DIR\SUBDIR\FILENAME.mp4
  • Turn ON JellyFin Server
  • Add DRIVE_LETTER (E:) into JellyFin\Dashboard\Libraries\LIBRARY_NAME
  • Rescan (ADD IN TEMP file(s))
  • Click CHECKMARK Twice in “Next Up” and/or “Continue” List
  • Rescan (Mark as Watched/Unwatched)
  • Delete Files
  • Rescan (Remove Series FILES REF from Library)
  • Delete DIRS
  • Rescan (Remove Series DIR REF from Library, Now only valid REF is Listed)
  • Remove External HDD 
  • DONE!

Clearing the Cache, Refreshing the DB, Eliminating remnants manually 
in the Windows Directory tracking Libraries

listed in "Next Up" and "Continue". 

3. Turning on the JellyFin Server I Added the ORIGINAL DRIVE LETTER that I had 
removed from the Library and Rescanned the JellyFin DB. 
(This allowed me to Mark the "Watched/Unwatched" checkmark.) 
The Show Finally disappeared out of the "Next Up" and "Continue" Lists. 

4. Preparing for TEMP Drive removal I deleted the .MP4 Show. Rescanned the DB.

5. Finally I noticed that I needed to clear the "Recently Added to" Library List, 
I removed the Drive Letter from the JellyFin Library DB

6. Rescanning the Drive again before HDD removal, I Deleted the .MP4 files from 
the Empty Drive.

7. Deleting the Physical Windows Folder I rescanned Again and JellyFin cleaned up 
Invalid Library References. 

8. I Disconnected my TEMP Drive from the Computer. The SHOW is now Referenced

Jellyfin - Force IMDB Movie ID

Problem:  Movie INFO would be forced on a File Inaccurately
Solution:  Name File:  Movie-Name (DATE) {imdb=##########}.mp4

Example:

Hummingbirds (2012) {imdb=tt3216766}.mp4

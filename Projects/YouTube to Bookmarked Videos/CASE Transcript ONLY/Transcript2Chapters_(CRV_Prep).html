  • VIDEO Downloaded

Working Procedure: Transcript to CRV (Still needs further Testing)

1. Replace:   (1 Line for Every Sentence - READABILITY)
([.?!])($|\s+)
with 
$1\r\n

2. ADD MANUALLY  (Insert before each Chapter Title)
Fact X.

3. Run Plug-In Columns++  (Change Static "Fact X" Label to "Fact #" Counter)
Search:
Fact X:
Replace:
Fact (?=match)
Result: Fact 1, Fact 2, Fact N...

4. REPLACE (AFTER Each "Time Signature" ADD a Carriage RETURN)
(\d{2}:\d{2}:\d{2})
with
\r\n\1

(Make Sure the first line does not have extra spaces after Time Signature)
5. Replace: (ZAP Extra Carriage Returns for LINES without TIME Signatures)
(^.*[a-zA-Z].*$)(\R)
with
\1 (SPACE)

PART 1: Time to Milli-Seconds

  • Formatting the Number into Standard “HH:MM:SS.ccc” Notation using NotePad++ Find/Replace 
CASE Based on No Milliseconds:  
1. N.  M:SS TEXT
2. N.  MM:SS TEXT
3. N. MM:SS TEXT
4. N. H:MM:SS TEXT
5. N.HH:MM:SS TEXT

NEXT:
1. Copy TIME BLOCK HH:MM:SS.ccc
2. Paste into Run of V2_TimeSig2MilliSec.bat
3. Open RESULT.txt, Copy Block back into MP4.csv Block
4. Continued with Macro2.txt

1. N  M:SS Time, End in Milliseconds
MODE: REGEX
FIND: (\.  )([0-9]):([0-9].) ([A-Za-z])
REPL: \100:0\2:\3\.000 \4

2.  N.  MM:SS Time, End in Milliseconds
MODE: REGEX
FIND: (\.  )([0-9].):([0-9].) ([A-Za-z])
REPL: \100:\2:\3\.000 \4

3. NN. MM:SS Time, End in Milliseconds
MODE: REGEX
FIND: (\. )([0-9].):([0-9].) ([A-Za-z])
REPL: \100:\2:\3\.000 \4

4. NN. H:MM:SS Time, End in Milliseconds
MODE: REGEX
FIND: (\. )([0-9].):([0-9].):([0-9].) ([A-Za-z])
REPL: \1\2:\3:\4\.000 \5

5. NNN.HH:MM:SS Time, End in Milliseconds
MODE: REGEX
FIND: (\.)([0-9].):([0-9].):([0-9].) ([A-Za-z])
REPL: \1\2:\3:\4\.000 \5
  •  Block COPY (ALT + Drag MOUSE) Copy Time Signatures

PART 2 - Achieving the Target Format

(Number).Milli-Seconds TEXT

Output Format:
(Number);Milli-Seconds-LOW;Milli-Seconds-HIGH;TEXT
where least-significant-digits are LOW=000 and HIGH=999

1.  Intermediate Format: (Number);Milli-Seconds-LOW;TEXT
    FIND:  (^\d{1,3})\.\s{0,3}\b(\d{4,8})\b\s{0,3}([a-zA-Z\s]*)$
    REPL:  \1;\2;\3
    
2.  Intermediate Format: (Number);Milli-Seconds-LOW;Milli-Seconds-LOWc;TEXT
    FIND:  (^\d{1,3});(\d{4,8});([a-zA-Z\s]*)$
    REPL:  \1;\2;\2c;\3
    
3.  Final Format:    (Number);Milli-Seconds-LOW;Milli-Seconds-HIGHc;TEXT
    FIND:  000c
    REPL:  999
    

Part 3 - Merging the MOVIE.MP4 and the MOVIE.csv

  • Drag-Drop Movie.MP4 onto Add_Bookmarks.bat
  • Output will be MOVIE_.mp4

Add_Bookmarks.bat

@Echo Off
setlocal enableDelayedExpansion

REM # Set Up File Variables 
SET META_FILE=MetaData.txt
SET MP4_FILE="%~n1%~x1"
SET MP4_NEW_FILE="%~n1_.mp4"
SET CSV_FILE=%~n1.csv

REM Work Around - For Loop Space Limitations
ren "!CSV_FILE!" Bookmarks.csv
REM echo "!CSV_FILE!"
REM pause
REM Debug: Verify
Echo META_FILE = !META_FILE!
Echo MP4_FILE = !MP4_FILE!
Echo MP4_NEW_FILE = !MP4_NEW_FILE!
Echo CSV_FILE = !CSV_FILE!

REM Extract MOVIE metadata previously existing 
ffmpeg -i !MP4_FILE! -f ffmetadata !META_FILE!
(Echo.)>>!META_FILE!

set /A i=0
echo.

REM Extract CSV DB info line by line
for /F "tokens=1,* delims=," %%a in (Bookmarks.csv) do (
    set /A i+=1
    set array[!i!]=%%a
)
echo Check

set /A n=!i!

REM Extract Line Info Delimited by Semi-Colons
for /L %%i in (2,1,!n!) do ( 
    REM @echo !array[%%i]!
    for /f "tokens=1,2,3,4 delims=;" %%a in ("!array[%%i]!") do (
        set /A FIRST_SEMI=%%a
        set /A SECOND_SEMI=%%b
        set /A THIRD_SEMI=%%c
        set FOURTH_SEMI=%%d

        REM Intermediate Errors Here are unseen and do not stop the program
        REM These are DB Based Errors and only appear as Warnings
        REM but they do not Stop the Program from working
        set /A SROUND=!SECOND_SEMI! + 0 2> nul
        set /A EROUND=!THIRD_SEMI! + 0 2> nul

        echo [CHAPTER]>>!META_FILE!
        echo TIMEBASE=1/1000>>!META_FILE!
        echo START=!SROUND!>>!META_FILE!
        echo END=!EROUND!>>!META_FILE!
        echo TITLE=!FOURTH_SEMI!>>!META_FILE!
        REM echo COUNT=!FIRST_SEMI!
        (echo.)>>!META_FILE!
    )
)

REM Rename the CSV DBFile back to its original name spaces and all
ren Bookmarks.csv "!CSV_FILE!"

REM Add New Chapter Files to Video
ffmpeg -i !MP4_FILE! -i MetaData.txt -map_metadata 1 !MP4_NEW_FILE!

REM Quietly delete MetaData.txt
REM del /Q !META_FILE!

REM DONE!

How to Generate Text from Audio with SubtitleEdit

(AI Generated Answer)

Step 1: Open your file

  • Launch Subtitle Edit.
  • Navigate to the menu and select Video > Open video file.
  • Choose the audio or video file you want to transcribe.
    • Although the dialog box is labeled for video, you can use the file type dropdown menu to select audio formats like .mp3 or .wav.

Step 2: Access the audio-to-text tool

  • Go to the Video menu again.
  • Select Audio to text (Whisper). Subtitle Edit also offers Vosk as an alternative, but Whisper is generally recommended for its superior accuracy.

Step 3: Configure settings and download models

Before the first use, you may need to install components and download language models.
  • Engine: The software will often suggest a fast, high-quality engine, such as Purfview's Faster-Whisper. It may prompt you to download it if you don't have it.
  • Language: Select the language spoken in your audio or video.
  • Model: Choose a model size. Larger models offer higher accuracy but take longer to process and download. The large-v3 model is often recommended for the best results.
  • Auto adjust timings: Check this box to have the software automatically time the generated text to the audio.
  • Post-processing: Enable this option for better results. This feature can help merge short lines, split long lines, and fix short durations.

Step 4: Generate the text

  • Click the Generate button to start the transcription process.
  • The software will transcribe the audio and populate the main text window with the generated subtitles.
  • The time required for this process depends on the length of your file and the model size you selected.

Step 5: Review and refine

The automated transcript will be highly accurate but may still contain errors.
  • Proofread: Read through the generated text and correct any spelling or punctuation mistakes.
  • Edit Timings: Review the timings to ensure the text syncs correctly with the audio.
  • Fix Line Breaks: Use the built-in tools to merge or split lines for better readability. You can right-click on a line and select from the "Merge with line before" or "Split line" options.

Step 6: Export your text

  • Once you are satisfied with the result, go to the menu and select File > Save As to save your work as an .srt file.
  • If you only need a plain text transcript, go to File > Export > Plain text. This option allows you to save the text in various formats, such as with or without time codes.

OCR using Free Utility tesseract

Usage:  

tesseract File.JPG JPG-TEXT.txt

Example Project:

  • Copy All Titles from YouTube Video using GreenShot
  • Capture Text from JPGs using “tesseract” OCR.

              3 Hours of Life Lessons So You Dont Screw Up Your life

(https://www.youtube.com/watch?v=1qJ8KWww50g)
Link Currently Active 09/23/2025

Note: (As of 09/23/25) 

This Video has no Timeline.  
This Video doesn’t give a list of messages.

First Step

Use GreenShot to Capture JPGs in Video using VIDEO: 
  • SHIFT+Right Arrow to Skip 1 minute forward in Video
  • Print-Screen to Capture Last Defined Region in Video to File

Second Step

  • Capture all the Titles from the JPGs using OCR and Append them to _OUTPUT.txt
  • Spell/Grammar Check.  I used Microsoft Word.

Save all Lines to _OUTPUT.txt

JPG2TXT.bat

@Echo Off
REM LOOP - OCR All Files
for %%f in (*.jpg) do (
    REM Save Text to 000.txt
    Call tesseract "%%f" 000
    
    REM 1 Sec Pause
    timeout /t 1 /nobreak > NUL
    
    REM Append First Line of 000.txt to _OUTPUT.txt
    Call Append_First_Line.bat
)

Append_First_Line.bat (to _OUTPUT.txt)

@echo off
for /f usebackq^ delims^=^ eol^= %%A in ("000.txt") do echo(%%A>>"_OUTPUT.txt"&goto :break
:break

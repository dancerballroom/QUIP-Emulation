AAA_MP4/MP3_MKDIR_MOVE.bat

Purpose:  Helper Utility
Used: After downloading YouTube Videos Using PotPlayer and turning them into MP3s to turn into Audiobooks.

Problem:  Repetitive Process: Creating Subdirectories for each MP4/MP3,  Placing each MPX-Name.* ->Subdirectory.

Pseudo Code:

For Each (MP3/MP4)
Create SubDir MP3-Name
Move MP3-Name.* into SubDir MP3-Name
Next For

AAA_MP4_MKDIR_MOVE.bat

REM Place in SendTo Direcoty

@Echo Off
    setlocal enableDelayedExpansion
    REM Create SubDIR for each mp3
    REM Move mp3 to SubDIR
    
    Set "ext=mp4"
    pushd "%~d1%~p1"
    echo "%~d1%~p1"
    cd

    REM Send Each MP3 to :Sub as %1
    For %%a In (*.%ext%) Do Call :Sub "%%~a"
    
    REM Call :EliminateUnderscores "%1"
    popd
    Exit /B

:Sub
    echo "%~n1"
    echo "%1"
    echo mkdir "%~n1"
    mkdir "%~n1"
    move "%~n1.*" "%~n1"
    cd "%~n1"
    
    REM Set up the Next Sub-Directory in the SubDir for the Next Step
    REM NEXT: Using MP3 Splitter Joiner PRO, Divide MP3 into 20 min segments
    mkdir "%~n1-20minutes"
    cd ..
    Exit /B

:ENDER

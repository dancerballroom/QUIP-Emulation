Mklink and Robocopy Incremental Backup

Typical Robocopy Transfer using External Hard Drive From "Download Computer" to "JellyFin Server Computer"  

robocopy C:\G-Manhwa C:\F-Manhwa /E /PURGE /XO /Z /r:5 /w:5

The Example Below is Going the Other Direction because the Files were Moved on the Target Hard Drive and the Backup HD Needed Mirroring.

1 . Windows Search: CMD

2. Open Command Window as Administrator

3. Run The Following 2 Mklink and 1 Robocopy Commands

Create Symbolic Link to "Manhwa Comics" on F:
mklink /D "C:\F-Manhwa" "F:Misc TALES STORIES and COMMENTARY Videos\Manhwa Comics"

Create Symbolic Link to "Manhwa Comics" on G:
mklink /D "C:\G-Manhwa" "G:Misc TALES STORIES and COMMENTARY Videos\Manhwa Comics"

Use Robocopy (Avoids winding up with duplicate files in alternare Dirs)
robocopy C:\F-Manhwa C:\G-Manhwa /E /PURGE /XO /Z /r:5 /w:5



BREAKDOWN (robocopy options):
1. /E                Copy all including Empty Directories
2. /PURGE            Deletes Files\Dirs in the DEST not in SOURCE
3. /XO               Excluding Overwrite Older Files
4. /Z                Resume Transfer if Interrupted
5. /r:5              retry up to 5 times (if CRC Check Errors)
6. /w:5              stop trying after 5 times (if CRC Check Errors)

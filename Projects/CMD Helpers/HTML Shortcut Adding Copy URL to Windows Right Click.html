HTML Shortcut Adding Copy URL to Windows Right Click

Issue: URL available in HTML Shortcut. You don’t want to open in browser.
Solution:


To add a "Copy URL" option to the Windows context menu for internet shortcuts, you can Use the Registry Editor (Open as Admistrator) to create a custom command that extracts the target URL and copies it directly to your clipboard.

Step 1: Open the Registry Editor
  1. Press the Windows Key + R to open the Run dialog.
  2. Type regedit in the box and press Enter to open the Windows Registry Editor. [1, 2]
Step 2: Navigate to the Shortcut Shell
  1. Paste the following path directly into the address bar at the top or find it in the left sidebar:
    HKEY_CLASSES_ROOT\InternetShortcut\shell
  2. Right-click the shell folder, select New, and click Key.
  3. Name this new key: Copy URL (or whatever name you want to see in the right-click menu). [1, 2, 3]
Step 3: Create the Command
  1. Right-click the Copy URL key you just made, select New, and click Key.
  2. Name this sub-key exactly command (lowercase).
  3. Click the command key. On the right side, double-click the (Default) value.
  4. Paste the following code into the Value data field:
    cmd.exe /c powershell -command "$target = (New-Object -ComObject WScript.Shell).CreateShortcut('%1').TargetPath; Set-Clipboard -Value $target"
  5. Click OK and close the Registry Editor.

No Access to Add Keys to Shell?

Answer: Change Owner to Users
If the shell is already running as 

an administrator but you still 

receive the error, 

the registry key might be locked 

down or owned by SYSTEM.
  • The Fix: Take manual ownership using REGEDT32 or RegEdit
  1. Press Win + R, type regedit, and hit Enter.
  2. Navigate to the parent directory where you want to create the key.
  3. Right-click the key and select Permissions → Advanced.
  4. Click Change next to the Owner, enter your username, and check "Replace owner on subcontainers and objects".
  5. Grant your user account Full Control permissions.

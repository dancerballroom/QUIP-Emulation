Make LibriVox (Free AudioBooks Files) USER friendly

Librivox free Audio Books in the Public Domain

Project Gutenberg free Texts in the Public Domain.  I like the Australian Site. (The rules for public domain books is a bit less strict).  

@Voice App to Use Cell to Turn TEXT into Voice

Problem to Solve:  Listening to the same disclaimer on every Chapter of your Audiobook gets OLD FAST
Solution:  Use a batch file to manipulate the ffmpeg utility.
Keep a little Disclaimer at the beginning and SHAVE off the Rest.  
Move it to your phone.  
Listen to your book using the “Music Folder” App.  (to keep track of where you left off)

REQUIRES:
  • ffmpeg in your path (free download/windows version)  Mine is in C:\FFMPEG\bin\ffmpeg.exe
  • Administrative USER Privileges to run Batch Scripts in Windows.

USAGE:
  • After placing the AAA_MP3_LibriVox-Start-Chop.bat in your SendTo DIR
  • Left Click on the first MP3, it automatically will play the chapters in order of occurrence.
  • You determine  how many seconds to SHAVE off, Type in the Number:  Maybe 10 or 10.5 or 17, or 0 (whatever)
  • Press Enter, the Processed File is Placed in the “Start_Trimmed” Sub Directory.
  • The Script Opens the Next Chapter and Prompts for the Number of Seconds to be SHAVED OFF until all files are processed.

COPY / Place BATCH File in Windows SendTo DIR

Typically:  c:\users\[username]\AppData\Roaming\Microsoft\Windows\SendTo

AAA_MP3_LibriVox-Start-Chop.bat

@Echo Off
setlocal enableDelayedExpansion
Set "ext=mp3"
pushd "%~d1%~p1"
echo "%~d1%~p1"
If Exist *.%ext% (If Not Exist "Start_Trimmed\" MD Start_Trimmed)

Call :EliminateSpaces

REM Send Each MP3 to :Sub as %1
For %%a In (*.%ext%) Do Call :Sub "%%~a"

Call :EliminateUnderscores
cd Start_Trimmed
Call :EliminateUnderscores
cd ..

popd
Exit /B

:Sub
cd
dir "%~n1.mp3"
Echo %~n1.mp3
Call "%~n1.mp3"
set /p chopSTART="Chop (S)econds -> "

REM Chop off the Specified Number of Seconds at the Beginning of the MP3
ffmpeg -ss !chopSTART! -i "%~n1.mp3" -acodec copy "Start_Trimmed\%~n1.mp3"
Exit /B

:EliminateSpaces
Set "Pattern= "
Set "Replace=_"

For %%a in (*.mp3) Do (
    Set "File=%%~a"
    Ren "%%a" "!File:%Pattern%=%Replace%!"
)
Exit /B

:EliminateUnderscores
Set "Pattern=_"
Set "Replace= "

For %%a in (*.mp3) Do (
    Set "File=%%~a"
    Ren "%%a" "!File:%Pattern%=%Replace%!"
)
Exit /B

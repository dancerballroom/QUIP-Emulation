Transient Toast Notification through Powershell


Code:

Note:  The PowerShell line is all One Line
set "title=My Notification"
set "message=This is a transient toast notification."

powershell -Command "$ws = New-Object -ComObject WScript.Shell; $notification = [Windows.UI.Notifications.ToastNotificationManager]::GetTemplateContent([Windows.UI.Notifications.ToastTemplateType]::ToastText02); $toastText = $notification.SelectNodes('//text'); $toastText.Item(0).InnerText = '%title%'; $toastText.Item(1).InnerText = '%message%'; [Windows.UI.Notifications.ToastNotificationManager]::CreateToastNotifier('PowerShell').Show($notification)"

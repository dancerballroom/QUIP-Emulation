Eliminate Commercials 
Trim Out unwanted sections of Video

1.  Drag-Drop "Some-Video.mp4" 
2.  Play the Video/Pause the Video
3.  The Many Ways To Create Cutting Blocks

Method 1: Using the Video Only
  Play/Pause
  Use Right and Left Arrow Keys
  to pin-point exact cut.
  Click "Mark Start" and "Mark End"
  
Method 2: Using the Wave Form Area
  Click, Drag, Release
  Move the Bars to Change the Start/End
  
Method 3: Using "Add Entry"
  Specify the Time Start and End
  Format: HH:MM:SS.mmm

4.  Export the Script that uses FFMPeg
    to do the heavy lifting.
    Also fixes DTS Errors.
    
Note: The Batch-file must be in the same
    directory as the MP4 Video.
    
Note: After running the Batch-file
    The Output will be placed in a 
    sub-directory called Merged.
    
The Created Batch-file requires FFMpeg,
a Free Command Line Interface Video
Manipulator.  Download and Install it.

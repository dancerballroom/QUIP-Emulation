----[ Min-Video-Player Control Help ]---- 
Drag-Drop Video = Load Video
{CNTRL + R} = Toggle Stretch

{CNTRL+SHIFT+H} = Show Help
{CNTRL+SHIFT+B} = Exit Back to Filing Cabinet
----[ Play/Pause/Help ]---- 
<SPACE> = Toggle Play/Pause
<ESC> = Close/Stop

----[ Jump Navigation ]---- 
{LEFT-ARROW} / {RIGHT-ARROW}
         Video (Rewind/Advance) 1 Minute 
{CONTROL} + {LEFT-ARROW} / {RIGHT-ARROW}
         Video (Rewind/Advance) 10 Seconds
{CONTROL}{SHIFT} + {LEFT-ARROW} / {RIGHT-ARROW}
         Video (Rewind/Advance) 1 Seconds
{CONTROL} + G
         Specify Time to Jump To

----[ Jump Navigation and Session Save/Load ]---- 
CNTRL + I = Info & Time Stamps

Video Information Screen
<Save Button> = Save Current Session (VID + TiimeSigs)
<Load Button> = Load Saved Session (VID + TimeSigs)

<Drag-Drop TEXT-AREA> Load TimeSigs Text File
for example:  AA_Black_Detect_Timestamps.txt
00:04:37
00:06:10
00:07:39

Offset 0-6 Sec Spinner
OCR Program Advance Past Black Screen

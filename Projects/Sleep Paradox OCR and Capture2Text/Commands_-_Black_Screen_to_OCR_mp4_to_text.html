Commands - Black Screen to OCR mp4 to text

  • Detect Black Screens (Extract Start Times in Seconds.MilliSeconds)
    • ffprobe -f lavfi -i "movie=input.mp4,blackdetect[out0]"
      -show_entries tags=lavfi.black_start -of default=nw=1 -v quiet
      > Black_Detect3.txt
    • ONE LINE:
      ffprobe -f lavfi -i "movie=input.mp4,blackdetect[out0]" -show_entries tags=lavfi.black_start -of default=nw=1 -v quiet > Black_Detect_3.txt

      OUTPUT:
      TAG:lavfi.black_start=201.8
      TAG:lavfi.black_start=201.8
      TAG:lavfi.black_start=306.2
      TAG:lavfi.black_start=306.2
      TAG:lavfi.black_start=430.033
      TAG:lavfi.black_start=430.033

  • NotePad: Delete Duplicate Entries
    • NotePad++ -> Edit Menu/Line Operations/Remove Duplicate Lines

      OUTPUT:
      TAG:lavfi.black_start=201.8
      TAG:lavfi.black_start=306.2
      TAG:lavfi.black_start=430.033
  • NotePad: Delete Junk Data
    • NotePad++ -> CTRL + ALT + ARROWS, <DEL>

      OUTPUT:
      201.8
      306.2
      430.033
  • Format Second to MilliSecond Decimal Data: (Example: 201.8 → 00:03:21:800)
    • Batch File: V1_Sec2TimeSig.bat

      OUTPUT:
      00:03:21.800 
      00:05:06.200 
      00:07:10.033
  • OCR (Text Extract) using CMD Window
    • Utility: Capture2Text_CLI.exe

Crop and Black Detect

  • Download Video
  • CNTRL + E to Snapshot an Area to Define X1, Y1, X2, Y2 Area Coordinates
  • Open with JPG Editor and Find Out X1, Y1, X2, Y2
  • Run CROP Command 
ffmpeg -i input.mp4 -vf crop=480:230:70:80 TEMP.mp4 -y
ffmpeg -i input.mp4 -vf "crop=w:h:x:y" output.mp4
(5:45 Minutes to Process 03:10:00 Video)
  • w: The width of the cropped area.
  • h: The height of the cropped area.
  • x: Horizontal offset from the left edge (default is center).
  • y: Vertical offset from the top edge (default is center).
  • Run BlackDetect Command 
ffprobe -f lavfi -i "movie=TEMP.mp4,blackdetect[out0]" -show_entries tags=lavfi.black_start -of default=nw=1 -v quiet > TEMP_Black_Detect.txt

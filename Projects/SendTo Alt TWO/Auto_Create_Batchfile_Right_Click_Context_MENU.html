Auto Create Batchfile Right Click Context MENU

Purpose:  Facilitate a Speedy Addition to the FILE (Right Click Context Menu)
NOTE:  LIMIT to Total of 16 (DIRECTORIES and BATCHFILES)
       In my Example I use 5 Directories and 11 Batchfiles 
       (5 + 11) = 16 MAX
       
Generator Files Required (2):
        Menu-Reg-Generator-V6.bat (Creates the Windows REG files)
        WIN_REG_MENU_GEN.bat (Converts Current DIR-FILE Structure)
            (Limitations: No Spaces, 16 Entries MAX)

                   or 14 Batchfiles(or Less) + 2 Directories
                   or 13 Batchfiles(or Less) + 3 Directories, etc.)

:: Check WMIC is available

:: Use WMIC to retrieve date and time
FOR /F "skip=1 tokens=1-6" %%G IN ('WMIC Path Win32_LocalTime Get Day^,Hour^,Minute^,Month^,Second^,Year /Format:table') DO (
   IF "%%~L"=="" goto s_done
      Set _yyyy=%%L
      Set _mm=00%%J
      Set _dd=00%%G
      Set _hour=00%%H
      Set _minute=00%%I
)
:s_done

:: Pad digits with leading zeros
      Set _mm=%_mm:~-2%
      Set _dd=%_dd:~-2%
      Set _hour=%_hour:~-2%
      Set _minute=%_minute:~-2%


:: Display the date/time in ISO 8601 format:
:: Set MyTime=%_yyyy%-%_mm%-%_dd%.%_hour%-%_minute%
:: Set MyDateTime=%_minute%-%_hour%_%_dd%-%_mm%-%_yyyy%
Set MyDateTime=%_hour%-%_minute%--%_mm%-%_dd%-%_yyyy%

2 of 2: WIN_REG_MENU_GEN.bat (Converts Current DIR-FILE Structure)

@Echo Off
SETLOCAL ENABLEDELAYEDEXPANSION
SET /a CNT=0
SET COMMANDS=%~d0%~p0\WIN_REG_MENU_GEN_COMMAND.txt

:process
for /r "%~d0%~p0" %%a in (.) do (
    set curdir_long=%%a

    set curdir_short=%%~nxa

    REM Chop off last character
    SET curdir=!curdir_long:^\.=!
    if "!CNT!" == "0" (
        echo 3C>!COMMANDS!
        echo !curdir_short!>>!COMMANDS!
    )
    
    if NOT "!CNT!" == "0" (
        Echo PUSHD      -^> !curdir! - !curdir_short!
        echo 1C>> !COMMANDS!
        echo !curdir_short!>> !COMMANDS!

        REM The next two lines take care of the ZERO Padding Problem
        set var_=00000!CNT!
        set var_=!var_:~-2!

        echo !var_!>> !COMMANDS!
        SET /a CNT=!CNT!+1

        pushd !curdir!

        for %%b in (*.bat) do (
            if NOT %%b == %~n0%~x0 ( 
                Echo               !curdir!\%%b - %%b
                Echo 2C>> !COMMANDS!
                Echo !curdir!\%%b>> !COMMANDS!
                Echo %%b>> !COMMANDS! 

                REM The next two lines take care of the ZERO Padding Problem
                set var_=00000!CNT!
                set var_=!var_:~-2!

                echo !var_!>> !COMMANDS!
                SET /a CNT=!CNT!+1
            )
        )
       popd 
       echo \-- ^> POP-PED !curdir!
    )
    SET /a CNT=!CNT!+1
)
Echo 0C>> !COMMANDS!
:ender
echo DONE!
pause

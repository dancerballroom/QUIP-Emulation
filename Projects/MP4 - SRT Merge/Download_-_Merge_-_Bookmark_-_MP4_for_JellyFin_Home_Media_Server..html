Download - Merge - Bookmark - MP4 for JellyFin Home Media Server.

This is the Improved Version.  Before I was using ClipGrab to Download YouTube Videos, I tried first to Download via PotPlayer’s TEMP Directory, but that method got shut down by YouTube over the last year or two.  Then I found a second method, using YT-DLP, which is fine for simple downloads and mounting of those downloads.  However when Merging YT-DLP downloads there were always errors with Encoding.  Since using ClipGrab, I find that Adding Bookmarks seems to be a process without Errors.  Cross Fingers Everything Keeps on Working for a Few Years Yet.

Since We need to Download each item in the playlist individually (ClipGrab doesn’t Support entire Playlist Download) we have to have each item’s URL and Description just to Keep things straight.

Estimated Time to Complete this Process

About 2 Hours to Merge 19 Shows (6 Hours), Add Bookmarks, and Make Streamable.
  • 1 Hr. Download 19 YouTube Videos
  • 20 Minutes to Format the CSV Bookmark file
  • 30 Minutes to Create Merged 6 Hour file
  • 10 Minutes to Add to JellyFin Home Media Server (Complete with Description)
NOTE:  A lot of time is saved using AHK, NotePad++, Batch File Programming, and Trial and Error.

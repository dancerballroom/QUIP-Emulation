It looks like Gobbledy-Gook, but the program recognizes the Numbers as Key Pressed, Durations, and Typed Keys.

Program Notes: 

  • Control + TAB was creating a bottleneck, waiting for users Mouse Click
  • I found out that Control + PGDN or Control + PGUP did the Job.
  • The Name Copying Part was a Fiasco.  It just doesn’t Macro at the Save AS Filename.
  • My fall back is to Search for *.LRC, click the current Filename, delete the ES/DE/EN, and save the LRC

To Polish Off I created MergeLRCHelper() and LRCHelper2() in AutoHotKey 2.0 to take care of the rest of 
the Clean-Up and Set-Up of the next 2 files.  
To Prep You need a SubDir called DONE (No other DIRS, except maybe BackUp for personal use)

MergeLRCHelper() operates Right-Click, Open, Run Macro Cntrl+Shift+9, Contrl+Shift+8, and Saves the Files
LRCHelper2() is for Clean-Up:  Delete, Archive, Set-Up/Highlight Next two files


MergeLRCHelper.AHK (AutoHotKey Macro file)

#Requires AutoHotkey v2.0
; Control + Shift + E
^+e::MergeLRCHelper()
; Control + Shift + R
^+r::LRCHelper2()
; Control + Shift + Q
^+q::SetupFolders()

; First Run - Establish Macro
MsgBox "Setting CTL + SHFT + E, `n`nFROM_Language-to-English`n`n(1. CTL+SHFT+Q = Setup Folders)`n`n(2. CTL+SHFT+E = Merge LRC - Open-Merge-Save)`n`n(3. CTL+SHFT+R = Clean-Up, Set-Up Next)`n`n`nNote: Highlight the Book.en.lrc and Book.xx.lrc and Hover over 1st Lang`n`nNotePad++ Prerequisite: No Loaded Files"

; # Exit Script 
Exit

; SRT2LRC.ahk 
; SAVE lrc & Translate to English & SAVE lrc

SetupFolders()
{
    ; Create Backup-LRC Folder
    Send "^+n"
    Sleep 500
    Send "Backup-LRC"
    Send "{enter}"
    Sleep 500

    ; Create Backup-SRT Folder
    Send "^+n"
    Sleep 500
    Send "Backup-SRT"
    Send "{enter}"
    Sleep 500

    ; Create Backup-LRC Folder
    Send "^+n"
    Sleep 500    
    Send "D-O-N-E"
    Send "{enter}"
    Sleep 500
    
    Send "{down}"
    Sleep 500

    ; Highlight the next 2 LRC files
    Send "+{down}"    
}

LRCHelper2()
{
    ;Delete Last 2 Files
    SendPlay "{delete}"
    Sleep 500
    Send "{enter}"
    Sleep 500 
    
    Send "{up}"
    Send "{down}"

    ; Cut the New .mp3 and .lrc
    Send "+{down}"
    Send "^x"

    ; CD DONE
    Send "{up}"
    Send "{up}"
    Send "{enter}"
    Sleep 500 

    ; Paste the New .mp3 and .lrc into DONE Directory
    Send "^v"
    Sleep 500 
    ; Back to the Parent Directory
    SendInput "{Backspace}"
    Sleep 500 
    Send "{down}"

    ; Highlight the next 2 LRC files
    Send "+{down}"    
}

MergeLRCHelper()
{
    ; Prerequisite:  Both .en and .de are Highlighted
    Sleep 300 

    ;Open both files into NotePad++
    MouseClick "right"
    Sleep 300 
    Loop 2
    { 
        Send "{Down}" 
        Sleep 200 
    }
    Send "{ENTER}"
    Sleep 500
    
    ;Operate the Cntrl+Shift+9 MACRO
    Send "^+9"
    Sleep 1000
    
    ;Operate the Cntrl+Shift+8 MACRO
    Send "^+8"
    Sleep 1000

    ;Save-As
    Send "^!s"
    Sleep 500

    ;Preformatted Filename
    Send "^v"
    Sleep 50
    
    ;Saved
    Send "{ENTER}"
    Sleep 50

    ;Close All
    Send "^+w"
    Sleep 50

    ;No, do not Save
    Send "o"
    Sleep 50

    ;Exit NotePad++
    Send "!{f4}"
}

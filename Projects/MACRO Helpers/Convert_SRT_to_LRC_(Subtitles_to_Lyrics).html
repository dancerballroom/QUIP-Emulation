Convert SRT to LRC (Subtitles to Lyrics)

Purpose:  Helper Script after SubtitleEdit downloads the TEXT for the current German Audiobook (.SRT)

Given:  
  • Der Hobbit (01 of 22).mp3
  • Der Hobbit (01 of 22).srt (Generated by SubtitleEdit’s Video/Audio to Text)

Output: 
  • Der Hobbit (01 of 22).de.lrc
  • Der Hobbit (01 of 22).en.lrc

Requires:  
  • AutoHotKey(v 2.0)
  • SubtitleEdit

Procedure:

  • Run the SRT2LRC.ahk below (This Establishes the Macro to run Next Time using Cntrl + ALT + E)
  • Open SubtitleEdit, Verify Shortcut established (Save As = (CNTRL+ALT+S))
  • Drag/Drop “Der Hobbit (01 of 22).srt” into SubTitleEdit
  • Click on SubTitleEdit Title Bar to Give this Application the Focus
  • Press (Cntrl + ALT + E) 
  • If successful it should take about 15 to 20 seconds to finish.  
    • (Do not click the mouse or type until Macro actions complete!)
    • Don’t run Twice on the same .SRT, it WILL BLOW UP
  • Go To Step 3 until DONE.

Followed by:

MEGA-MACRO - Automate Merge of ENGL/FREN .lrc

Following:  
  • Script for German-English
  • Script for Spanish-English

SRT2LRC (German-English).ahk

#Requires AutoHotkey v2.0
; Control + Shift + E
^+e::SRT2LRC()

; First Run - Establish Macro
MsgBox "Setting CTL + SHFT + E, `n`nGerman-English`n`n(CTL+SHFT+E = SRT2LRC - Save-Translate-Save)`n`nNote: SubtitleEdit -> Set Cntrl+Alt+S = Save As (1st)"
; # Exit Script 
Exit

; SRT2LRC.ahk 
; SAVE lrc & Translate to English & SAVE lrc

SRT2LRC()
{
    ; Give Subtitle Edit time to load
    Sleep 300 

    ; SAVE lrc
    ; CNTRL+ALT+S
    Send "^!s"
    Sleep 1000 

    ;ADD GERMAN ".de.lrc" 
    Send "{right}"
    Loop 3
    { 
        Send "{left}" 
    }
    Send "de."
    Sleep 1000 
    Send "!s"
    Sleep 1000 
    Send "{enter}"
    Sleep 300 

    ; Translate to English
    ; CNTRL+SHFT+G
    Send "^+G"  
    Sleep 200
    ; Make Sure German is Translated FROM
    Send "a"
    Sleep 200
    Loop 3
    { 
        Sleep 200
        Send "g" 
    }
    Sleep 200
    ; Make Sure English is Translated TO
    Loop 3
    { 
        Send "{tab}" 
    }
    Sleep 200
    Send "a"
    Sleep 200
    Send "e"
    Sleep 200
    Send "{tab}"
    Sleep 200
    Send "{ENTER}"
    
    ; Translation Lag Variable
    Sleep 11000    ; Command Load Time (Could Vary)
    Send "{tab}" 
    Send "{ENTER}"
    Sleep 300 

    ; Cntrl + Alt + Save = Saves X.en.lrc
    Send "^!s"
    Sleep 300 
    Send "{enter}"
    Sleep 600 
    Send "^n"    
}

SRT2LRC (No Translation).ahk - Add English Lyrics 

Prerequisite:  Model Added:  vosk-model-en-us-0.22
#Requires AutoHotkey v2.0
; Control + Shift + E
^+e::SRT2LRC()

; First Run - Establish Macro
MsgBox "Setting CTL + SHFT + E, `n`nSRT-2-LRC`n`n(CTL+SHFT+E = Save)`n`nNote: SubtitleEdit -> Set Cntrl+Alt+S = Save As (1st)"
; # Exit Script 
Exit

; SRT2LRC.ahk 
; SAVE lrc & Translate to English & SAVE lrc

SRT2LRC()
{
    ; Give Subtitle Edit time to load
    Sleep 300 

    ; OPEN
    Send "{ENTER}"
    Sleep 2000 
    
    ; SAVE AS
    ; CNTRL+ALT+S
    Send "^!s"
    Sleep 1000 

    ; LRC SAVED
    Send "{ENTER}"
    Sleep 1000 
    
    ; CLOSE
    ; ALT+F4 
    Send "!{F4}"
    Sleep 2000 
    
    ; PREP NEXT
    Send "{DOWN}"
}


Programming Notes:

Do not Program if you are sleepy
Damn if I did not get confused by the Macro Language of NotePad++ 
versus the Macro Language of AutoHotKey.  That cost me a couple of hours.

To Be Aware
Depending on the length of the sound file being processed the number of seconds
alloted to translation should be adjusted.  The Audible chapters I had here were about
20 minutes long or less.  Speed of the computer processor might also be a factor.

Prerequisite:  Adding Shortcut to SubtitleEdit 
# (Won't run without it)
Subtitle Edit Configuration: Create or Verify a Shortcut: 
     1. Options/Settings/Shortcuts/File/Save-As   (CNTRL+ALT+S)

I noticed that the Shortcut disappeared after a reboot.  Not sure why.

The reason that each language has its own Script (Non-Generic Script).
1.  The extension I choose:  Spanish=es, German=de, French=fr
2.  When doing the translation the number of keystrokes varies 
    when choosing the Translate FROM and Translate TO (depending on the language)
    (I found out if you do not force the Specific Choice, the language may change 
    arbitrarily.  For example:  German to Albanian or German to German)

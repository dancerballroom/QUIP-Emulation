Uses: AHK, Windows File Explorer, ClipGrab, NotePad++, Subtitle Edit

Step 1: The Setup (EST: 10 Minutes) Downloading File / Transcript

  1. Run TRANSCRIPT_FIX_4.AHK
  2. Copy Video Name from ClipGrab
  3. Download Video Using ClipGrab
  4. CNTRL+SHIFT+O (File Explorer)
    1. Create Text File with Copied Name
  5. Transcript into Text File using NotePad++

Step 2: Format the Transcript (EST: 10 Minutes)

  1. CNTRL+SHIFT+E (NotePad++)
    1. Copy Time-Sigs to New1.txt
  2. Click in the Middle of Time-Sigs
  3. CNTRL+SHIFT+T (NotePad++)
    1. Format Time-Sigs (00:00:00)
  4. Click on [Transcript Name].txt
  5. CNTRL+SHIFT+R (NotePad++)
    1. Remove All Time-Sigs
  6. CNTRL+SHIFT+I (NotePad++)
    1. Remove all ## Hours ## Minutes ## Seconds
  7. Click on New1.txt
  8. Click in the Middle of Formatted Time Sigs
  9. CNTRL+SHIFT+Y (NotePad++)
  10. Merge New.txt with [Transcript Name].txt
  11. Save [Transcript Name].txt, Close NotePad++_

Step 3: Format TXT in SubTitleEdit (EST: 5 Minutes)

  1. Open DRAG/DROP [Transcript Name].txt, in SubTitleEdit
  2. CNTRL+SHIFT+] (SubTitleEdit), WAIT
    1. Break/Split Long Lines
  3. Shift+TAB(x3), ENTER (Save Changes)
  4. Repeat Step 17 and 18 (IF any Changes Highlighted)
  5. CNTRL+SHIFT+S (SubTitleEdit)
    1. Save TXT file as .SRT
  6. ENTER (Save Changes)
  7. CNTRL+SHIFT+N (SubTitleEdit)
    1. NEW / Clear SubTitle Edit for Next Drag/Drop or Open TXT File

SRT2LRC (French-English).ahk

Purpose:   
  • Save [Audiobook.SRT] AS [Audiobook.FR.LRC]
  • Translate [Audiobook.FR.LRC] to English
  • Save [Audiobook.EN.LRC] 

Requires:

  • SubtitleEdit
  • SubtitleEdit → Set Cntrl+Alt+S Shortcut = Save As
    • SubtitleEdit MENU: Options/Settings/Shortcuts/File/Save As
  • Files created by SubtitleEdit and Associated MP3 
(MENU: Video :: Video/Audio to Text :: Batch Operation) - ForEach MP3 there is an SRT
    • [Audiobook].srt (French Subtitles)
    • [Audiobook].mp3

Script Prep (Pre-Procedure: For Ease - Set-Up the Directory View)

  • View Details / Sort by TYPE / Find the First .SRT

Procedure:

  • DoubleClick SRT2LRC (French-English).AHK to Instantiate Macro
  • Do-Loop
    • Drag/Drop .SRT onto SubtitleEdit
    • Focus:  SubtitleEdit
    • Press Cntrl+Alt+E
      • Creates [Audiobook.FR.lrc]
      • Translates to English
      • Creates [Audiobook.EN.lrc]
      • Closes LRC files for next DRAG/DROP
    • Wait for SubtitleEdit to Close before next DRAG/DROP

SRT2LRC (German-English).ahk

#Requires AutoHotkey v2.0
; Control + Shift + E
^+e::SRT2LRC()

; First Run - Establish Macro
MsgBox "Setting CTL + SHFT + E, `n`nFrench-English`n`n(CTL+SHFT+E = SRT2LRC - Save-Translate-Save)`n`nNote: SubtitleEdit -> Set Cntrl+Alt+S = Save As (1st)"
; # Exit Script 
Exit

; # SRT2LRC.ahk 
; #   SAVE lrc & Translate to English & SAVE lrc

SRT2LRC()
{
    ; # Give Subtitle Edit time to load
    Sleep 300 

    ; # SAVE lrc
    ; # CNTRL+ALT+S
    Send "^!s"
    Sleep 1000 

    ; # ADD FRENCH ".fr.lrc" 
    Send "{right}"
    Loop 3
    { 
        Send "{left}" 
    }
    Send "fr."
    Sleep 1000 
    Send "!s"
    Sleep 1000 
    Send "{enter}"
    Sleep 300 

    ; # Translate to English
    ; # CNTRL+SHFT+G
    Send "^+G"  
    Sleep 200
    ; Make Sure French is Translated FROM
    Sleep 200
    Loop                 3
    { 
        Sleep 200
        Send "f" 
    }
    Sleep 200    ; # Make Sure English is Translated TO
    Loop 3
    { 
        Send "{tab}" 
    }
    Sleep 200
    Send "a"
    Sleep 200
    Send "e"
    Sleep 200
    Send "{tab}"
    Sleep 200
    Send "{ENTER}"
    
    ; # Translation Lag Variable
    Sleep 11000    ; Command Load Time (Could Vary)
    Send "{tab}" 
    Send "{ENTER}"
    Sleep 300 

    ; # Cntrl + Alt + Save = Saves X.en.lrc
    Send "^!s"
    Sleep 300 
    Send "{enter}"
    Sleep 600 
    Send "^n"    
}

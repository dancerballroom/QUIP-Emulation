MergeLRCHelper.AHK

Also in MEGA-MACRO - Version 2.0

Purpose:   Help Merge Two Audiobook Lyric Files (.lrc) for use on Devices supporting local lyrics.

Output Example:

[ti:01 of 19 - 2001 Odyssee Im Weltraum - Arthur C. Clarke - 1968]
[00:00.00] If from heat and pressure
[00:00.00] ===
[00:00.00] Wenn aus hitze und druck
[00:01.11] 
[00:01.23] during the moons formation time.
[00:01.23] ===
[00:01.23] während der entstehungszeit des mondes.
[00:03.24] 
[00:04.23] But he knew that even this remote possibility had already been considered.
[00:04.23] ===
[00:04.23] Doch er wusste dass auch diese entfernte möglichkeit bereits ins auge gefasst.
[00:07.92] 

Requires:

  • NotePad++ (Set as Default Application to Open .LRC files)
  • NotePad++:  No Other Files open in NotePad++ (Only Empty New: Default)
  • Files created by SRT2LRC and the associated MP3:
    • [Audiobook].lrc.en (English Lyrics)
    • [Audiobook].lrc.de (German Lyrics)
    • [Audiobook].mp3
  • SubDirectory (See Procedure below)

Procedure:

  • DoubleClick MergeLRCHelper.AHK
  • Script 1st Run
    • Focus:  Explorer (MP3 Directory With .mp3, *.en.lrc, *.de.lrc, Organized by Name A-Z)
    • Press Cntrl+Shift+Q.  This Creates the following Subdirectories.
  • Manually Move All SRT to Backup-SRT (If they exist)
  • Manually Copy All LRC to Backup-LRC (In case of Catastrophic Macro FAIL)
  • Script Prep:
    • Open an LRC and make sure that the editor only has New file open when closing
    • Focus:  Explorer (MP3 Directory With .mp3, *.en.lrc, *.de.lrc, Organized by Name A-Z)
    • Highlighted:  First Two LRC files
      • [Audiobook].lrc.en (English Lyrics)
      • [Audiobook].lrc.de (German Lyrics)
    • Mouse:  Hover over either LRC file
  • Do-Loop
    • Make Sure both LRC are Highlighted and Mouse is positioned
    • Press Cntrl+Shift+E. 
      • Creates [Audiobook.lrc]
    • Wait until NotePad++ Closes
    • Press Cntrl+Shift+R
      • Moves MP3 and [Audiobook.lrc] into D-O-N-E
      • Highlights next two LRC Files

MergeLRCHelper.AHK

#Requires AutoHotkey v2.0
; Control + Shift + E
^+e::MergeLRCHelper()
; Control + Shift + R
^+r::LRCHelper2()
; Control + Shift + Q
^+q::SetupFolders()

; # First Run - Establish Macro
MsgBox "Setting CTL + SHFT + E, `n`nFROM_Language-to-English`n`n(1. CTL+SHFT+Q = Setup Folders)`n`n(2. CTL+SHFT+E = Merge LRC - Open-Merge-Save)`n`n(3. CTL+SHFT+R = Clean-Up, Set-Up Next)`n`n`nNote: Highlight the Book.en.lrc and Book.xx.lrc and Hover over 1st Lang`n`nNotePad++ Prerequisite: No Loaded Files"

; # Exit Script 
Exit

; # MergeLRCHelper.AHK 
; #   1. Helps Create Backup Folders
; #   2. Opens [Audiobook].srt
; #      Saves [Audiobook].DE.lrc
; #      Translates into English
; #      Saves [Audiobook].EN.lrc

SetupFolders()
{
    ; # Create Backup-LRC Folder
    Send "^+n"
    Sleep 500
    Send "Backup-LRC"
    Send "{enter}"
    Sleep 500

    ; # Create Backup-SRT Folder
    Send "^+n"
    Sleep 500
    Send "Backup-SRT"
    Send "{enter}"
    Sleep 500

    ; # Create Backup-LRC Folder
    Send "^+n"
    Sleep 500    
    Send "D-O-N-E"
    Send "{enter}"
    Sleep 500
    
    Send "{down}"
    Sleep 500

    ; # Highlight the next 2 LRC files
    Send "+{down}"    
}

LRCHelper2()
{
    ; # Delete Last 2 Files
    SendPlay "{delete}"
    Sleep 500
    Send "{enter}"
    Sleep 500 
    
    Send "{up}"
    Send "{down}"

    ; # Cut the New .mp3 and .lrc
    Send "+{down}"
    Send "^x"

    ; # CD DONE
    Send "{up}"
    Send "{up}"
    Send "{enter}"
    Sleep 500 

    ; # Paste the New .mp3 and .lrc into DONE Directory
    Send "^v"
    Sleep 500 
    ; # Back to the Parent Directory
    SendInput "{Backspace}"
    Sleep 500 
    Send "{down}"

    ; # Highlight the next 2 LRC files
    Send "+{down}"    
}

MergeLRCHelper()
{
    ; # Prerequisite:  Both .en and .de are Highlighted
    Sleep 300 

    ; # Open both files into NotePad++
    MouseClick "right"
    Sleep 300 
    Loop 2
    { 
        Send "{Down}" 
        Sleep 200 
    }
    Send "{ENTER}"
    Sleep 500
    
    ; # Operate the Cntrl+Shift+9 MACRO
    Send "^+9"
    Sleep 1000
    
    ; # Operate the Cntrl+Shift+8 MACRO
    Send "^+8"
    Sleep 1000

    ; # Save-As
    Send "^!s"
    Sleep 500

    ; # Preformatted Filename
    Send "^v"
    Sleep 50
    
    ; # Saved
    Send "{ENTER}"
    Sleep 50

    ; # Close All
    Send "^+w"
    Sleep 50

    ; # No, do not Save
    Send "o"
    Sleep 50

    ; # Exit NotePad++
    Send "!{f4}"
}

MP3 Foreign Language Lyric Generator

Purpose:  Generate Foreign Subs added to MP3 Sound Files  
and Convert into English-German, or French/Spanish/Etc. into Cell Phone Lyrics




Requires:  Subtitle Edit (Free Subtitle Editing Software)
  • Usually creates .SRT for Videos
  • We use it to create .LRC for Audio
Requires:  Musicolet (Free MP3 Player that allows you to view Lyrics)
  • Android Version (Maybe others?)

Addendum:  After Batch Extract of All Subs(.srt) for all book/books: 

  • Convert SRT to LRC (Subtitles to Lyrics)

Example of Adding English Subs to German MP3

  • Open Empty Subtitle Edit Window
  • Drag/Drop MP3 into Play Window
  • Click on the Black Strip at the Bottom (to add the Wave Form)
  • Click Menu:  Video then Video-Audio to Text
  • Click Ellipses ...
  • Choose German - Model Large or whatever language you are translating into.
  • Click Download
  • Choose the Language Model:  vosk-model-de-(version)
  • Click Generate
  • Wait for Program to Generate Subtitles
    • Loading/Transcribing (4min. to finish 20min.)

Now to get the English Translation

  • Menu:  Auto-Translate
    • Language: English
  • Click Translate.  Click OK if message shows.
  • Check translation.  Make corrections to Subs/Lyrics.  (There are usually a lot)
  • Save as a LRC or Lyric File  (Keep both English and German to create DUAL Lyrics: below) 
NOTE:  The best Music Player for my Android Phone
        that allows LRC I have found is Musicolet
        Musicolet has SETTINGS that need to be changed to view Lyrics (LRC) 
        There is what looks like a Page ICON that allows you to view the Lyrics/Subs

One further Step:  Having both English and German available:

Save 1 file in German:

01 of 19 - 2001 Odyssee Im Weltraum - Arthur C. Clarke - 1968.de.lrc

Save 1 file in English:

01 of 19 - 2001 Odyssee Im Weltraum - Arthur C. Clarke - 1968.en.lrc

Merge the two using the type command 

from the cmd (Windows command prompt) 

1.  type "01 of 19 - 2001 Odyssee Im Weltraum - Arthur C. Clarke - 1968.de.lrc" > "01 of 19
- 2001 Odyssee Im Weltraum - Arthur C. Clarke - 1968.lrc"
2.  type "01 of 19 - 2001 Odyssee Im Weltraum - Arthur C. Clarke - 1968.en.lrc" >> "01 of 19
 - 2001 Odyssee Im Weltraum - Arthur C. Clarke - 1968.lrc"
3.  Open the Lyric file (.lrc) with NotePad++
4.  Edit/Line Operations/Sort as Numbers Ascending

Or use the following Batch File: 

Click the two files and left click Open With(SendTo)  Concat.bat

Concat.bat

@Echo off
Setlocal enabledelayedexpansion

Set File1="%~n1%~x1"
Set File2="%~n2%~x2"
Set File3=!File1:~0,-8!.lrc"

type !File1! > !File3!
type !File2! >> !File3!    

A Couple of Fixes:

  • Move the last line (the Title) to the first line after SORTING
  • NOTE:  On Each line If you don’t care the order of ENG/GERM or GERM/ENG, (they will flip-flop based on which is alphabetically first), just leave things be.  Otherwise SLOG thru making the adjustment!

SEE Sorting It Out - Addendum to MP3 Foreign Language Lyric Generator 

to FIX the Sorting order.

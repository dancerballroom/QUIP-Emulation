Using 
* Chrome Browser
* ClipGrab 
* TRANSCRIPT_FIX_6.AHK
* NotePad++ w/Macros and Addons

START 
Run TRANSCRIPT_FIX_6.AHK

BROWSER
1.  Paste YouTube URL into ClipGrab
2.  Format and Copy Name
3.  Save to Working Folder

FILE EXPLORER
4.  CNTRL+"O" (Create Text File with Copied Name)

YOUTUBE
Video Comment Section
5. Click "More"
6. Show Transcript
7. CLICK+DRAG TOP PORTION
8. SHIFT (KEEP DOWN)
9. Scroll to Bottom of Transcript
10. Click to Right of Last line of Transcript
11. CNTRL + "C"

NOTEPAD++
12. Paste Into Text File

IF weird "Hours Minutes Seconds" format 
     GOTO :ReFormat
Else
     GOTO: Macro
ENDIF

:Macro
13.  CNTRL + SHIFT + 7 (TRANS2SRT)
GOTO :TXT2SRT

:ReFormat
13. CNTRL+ SHIFT + E (Separate Out HH:MM:SS) from Transcript to NEW Window
14. CNTRL + SHIFT + T (Standardize HH:MM:SS Format)
15. CNTRL + DN (Transcript Window)
16. CNTRL + SHIFT + R (Delete Non-Standard HH:MM:SS from Transcript)

If CNTRL+H (Find/Replace) Pre-populated 
   GOTO :PREP
Else
   GOTO :RUN_PREPPED
ENDIF

:PREP
CNTRL + H (Find/Replace) in ORDER
TEST: Press CNTRL + PGDN (#1 should show if Prepped)
1.  (^\shours, \d*) with BLANK
2.  (^\shour, \d*) with BLANK
3.  (^\sminutes, \d*) with BLANK
4.  (^\sminute, \d*) with BLANK
5.  (^\sseconds) with BLANK
6.  (^\ssecond) with BLANK
7.  (^\sminutes) with BLANK
8.  (^\sminute) with BLANK

:RUN_PREPPED
CNTRL + SHIFT + I (Operate Prepped Operations 1-8 Above)

:TXT2SRT
SUBTITLE EDIT
31. Drag-Drop Transcript.TXT into "Subtitle Edit"
32. IF "Subtitle Edit" Does Not Have Focus, Click "SubTitle Edit" Title Bar
33. CNTRL + ]  (TOOLS/BREAK-SPLIT Long Lines)
34. CLICK OK
35. CNTRL + ]
36. CLICK OK
37. CNTRL + SHIFT + S (Save As "SRT")
38. CLICK OK
39. CNTRL + N (New Project)
40. ALT + F4 (Exit Subtitle Edit)

END
CNTRL+X (UnLoad TRANSCRIPT_FIX_6.AHK)

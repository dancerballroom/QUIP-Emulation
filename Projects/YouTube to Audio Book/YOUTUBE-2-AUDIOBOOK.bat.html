YOUTUBE-2-AUDIOBOOK.bat

Purpose:  YouTube often has Audiobooks available that I would like to either listen to on my JellyFin Movie Server or Listen to From my Cell Phone.  Sometimes I like to have the Audio have Subtitles OR LYRICS (.LRC) which can be read by the Cell App Musicolet.

Solution: YOUTUBE-2-AUDIOBOOK.bat (Procedure Batch File)

Supportive Scripts:
  • Save-YouTube.bat ( yt-dlp YouTube Down Load Program)
  • Webm_2_mp4.bat ( FFMpeg Utility)
  • MP4_2_MP3.bat  ( FFMpeg Utility )
  • Prepping Transcripts for SRT conversion ( NotePad++   CNTRL+SHIFT+7  Macro )
  • AAA-MP3-SPLIT-20.bat (Uses mp3splt, Output DIR: DONE-LRC)
  • BBB_SRT_SPLIT_20_2_LRC.bat (Splits SRT, Converts to LRC, Output DIR: DONE-SRT and DONE-LRC) 

YOUTUBE-2-AUDIOBOOK.bat

@Echo Off
Echo Save YouTube Video to MOVIE-AUDIO AUDIOBook Procedure
Echo.
Echo ---[ Part 1 - VIDEO (MP4 and SRT) ]---
Echo 1.  Run CMD in CURDIR

REM Not Used Much, So Remmed out for the time being...
REM start cmd.exe /c cmd.exe /K Echo 2.  Run yt-dlp YouTube-URL
REM type NUL > Transcript.txt
REM Echo Creating Transcript.txt

Echo 2.  Run yt-dlp YouTube-URL
Echo 3.  While waiting, Copy from YouTube to Transcript.txt
Echo     --Select First Line of YouTube Transcript
Echo     --Scroll to Bottom
Echo     --Shift+Click
Echo     --Control+C
Pause
Echo 4.  DRAG-DROP Target.webm ONTO webm_2_mp4.bat
Pause
Echo 5.  REN Transcript.txt TO TargetName.txt
Pause    NOTEPAD++
Echo     Prep TargetName.txt - CNTRL+SHIFT+7
Echo 6.  Subtitle Edit TargetName.txt
Echo     Save-As Target.srt
Echo     --Fix Common Errors - TOOLS - CNTRL+SHFT+F
Echo     --Change Casing - TOOLS - CNTRL+SHFT+C
Echo     --Split Long Lines - TOOLS
Pause
REM -- [ FINAL (Corrected) METHOD ] --
Echo ---[ Part 2 - AUDIO (MP3 and LRC) ]---
Echo 7.  (MP4) SendTo MP4_2_MP3.bat
Echo     Use MP3 Tag to add Meta-Data
Echo 8.  (MP3) SendTo AAA-MP3-Split-20.bat (Uses mp3splt)
Echo 9.  (MP3 and MP4) Use MP3tag - TOOLS - Auto Number Wizard (CNT-K)    
Echo         NOTE:  Each Part is 20:17 with 10 second overlap
Echo 10. (SRT) SendTo SRT_Split_20_to_LRC.bat
Echo           If Using SRT Delete final 0-byte SRT file created.
Pause
Echo 11.  Play MP3 checking LRC Lyrics 
Echo 12.  Copy Book.mp4 and Book.srt to JellyFin Book Video (Local Movies Server)
Echo 13.  Copy Book.mp3 and Book.lrc
Echo        to Book Audio (Android Phone Micro-SD)
Echo      NOTE: Android APP Musicolet (Supports MP3 with Lyrics)
Echo            Android APP Music Folder (MP3 - No LRC - Tracking Yes)
Pause
Echo DONE!
pause

CSV Builder - Add Bookmarks - ReadMe.txt

  • Download MP4s using ClipGrab into DIR “Part 1 - Downloaded Files”
    • Double-Check Videos for English 
    • Appropriate Content
    • Subject Similarity
  • Merge MP4 using Batch File or ShotCut
    • IF DTS Timing Errors during Batchfile, use ShotCut
  • (CTL) Select Videos, Drag-Drop onto (CREATES BASIC.csv)
    • _01 - Entry Point - Add_Bookmarks_CSV_Generator.bat
    • If NO CSV then Replace Spaces in MP4 with Underscore (AAA_Search_Replace.bat)
    • Try Again
    • Now you have the BASIC CSV with FILEname Bookmarks
  • Add Bookmarks within FILEname Bookmarks
    • Create CSV with OFFSETS listed in Between Compilation FILEname Bookmarks
    • Use the three Utilities to Create CSV
      • UTILITY - OFFSET_TimeSig2MilliSec.bat
      • UTILITY - TimeSig2MilliSec.bat
      • UTILITY - MilliSeconds2HHMMSS

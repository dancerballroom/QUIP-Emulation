After Following Bat / Batchfile / Batch file 2 EXE

  • Arg_C.exe renamed ArgCountX.exe
    • ArgCountX.exe /?

Go to Solution

Research:


  • Normal running of Batch file ArgCount.bat 
C:\BATCH-SCRIPTS>ArgCountX.bat 1 2 3 4
arguments: 1 2 3 4
argument count: 4
Press any key to continue . . .
  • Weirdo Working (No Batchfile present, so it’s inside the EXE) 
ArgCountX.exe /c:"cmd.exe /c ArgCount.bat 1 2 3 4 5 6"
   /c:<CMD> = Override install Command defined by author
   cmd.exe = New cmd window
        /c = Carry out cmd and terminate process
        ArgCount.bat = Batch file: Print %* and Print %Argument_Count%

Result:
    1.  New Window Opens
    2.  Output:
    
        arguments: 1 2 3 4 5 6
        argument count: 6
        Press any key to continue . . .
  • Conclusion:  IExpress only creates a wrapper EXE for The Batch file (BAT)!
    • IExpress only has 4 cmd line options:  


  • IExpress is OK ( not passing Command Line Variables )

SOLUTION:

1.  Batch File Menu (to Process %1 - %9) - ArgCountXTest.Bat

# (NOTE: ArgCountX.bat is in the ArgCountX.exe)
@ECHO OFF
CLS

SET CurDir=%~d0%~p0

:: # Menu
:MENU
ECHO Use of IExpress
ECHO ..................................
ECHO . ArgCountX Examples - 5 to Exit .
ECHO ..................................
ECHO.
ECHO ..................................
REM ECHO .    1 - Minimized + Hard Coded  .
ECHO .    2 - Maximized + Hard Coded  .
ECHO .    3 - Maximized + Dynamic     .
ECHO .    4 - EXIT                    .
ECHO ..................................
ECHO.

:: # Choice
SET /P M=Type 1-4 then press ENTER:
REM IF %M%==1 GOTO Example1
IF %M%==2 GOTO Example2
IF %M%==3 GOTO Example3
IF %M%==4 GOTO EOF

:: # Functions
:Example1
Call %CurDir%ArgCountX.exe /c:"cmd.exe /c start /MIN %CurDir%ArgCountX.bat 1 2 3 4 5 6"
GOTO MENU

:Example2
Call %CurDir%ArgCountX.exe /c:"cmd.exe /c %CurDir%ArgCountX.bat 1 2 3 4 5 6"
GOTO MENU

:Example3
SET ARG1=%*
Call %CurDir%ArgCountX.exe /c:"cmd.exe /c %CurDir%ArgCountX.bat %ARG1%"
GOTO MENU

2.  Converted BAT2EXE - ArgCountX.EXE

@Echo Off
set argcount=0

:: # Loop Through All Args
for %%i in (%*) do (
    :: # Count Arguments
    set /a argcount+=1
    Echo Argument %%i: %%i
)

Echo argument count: %argcount% 
pause

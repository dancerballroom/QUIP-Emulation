Robocopy - Mirroring Options

Backup... Backup... Backup...

Before Starting Clear out ALL unwanted FILES, copy all files on DEST to SOURCE you want to keep and CLEAR OUT the Recycle Bin including HIDDEN Recycle Bin Remnants so as NOT to waste time copying the drives $Recycle Bin

Example:

rd /s /q <drive_letter>:\$RECYCLE.BIN

The Command I need to Mirror My External Hard Drives:

Mirror L:\ Drive onto E:\Drive
robocopy C:\Source D:\Destination /E /PURGE /XO /XN /Z 
BREAKDOWN:
1. /XO and /XN       Excluding Overwrite Newer or Older
2. /PURGE            Deletes Files\Dirs in the DEST that are not in SOURCE
3. /Z                Resume Transfer if Interrupted
4. /mt:8 (also /mt)  8 Simultaneos Threads is the default
5. /LOG:Logname.txt  Log/History of Transfers and Deletions

is preferred over
                                               NOTE:
robocopy C:\Source D:\Destination /MIR         -> Overwrite DEST NEWER and OLDER
robocopy <SOURCE> <DEST> /E /MIR /Z /mt:8      -> Better, Resumable, still Overwrite     
robocopy <SOURCE> <DEST> /E /MIR /Z /mt:8 /XO  -> Exclude Older Overwrite Newer

It’s all in the Switches!

/E = Copy all DIRS/FILES including Empty Ones
/PURGE = Delete DIRS/FILES in Destination not found on the Source
/XN = Exclude copying Newer Files to Destination found on the Source 
/XO = Exclude copying Older Files to Destination found on the Source
/Z = Mode: Resume Transfer if Interrupted

NOT USED

/mt8 = Multi-threaded copying, with 8 threads simultaneously
/r:5 = 5 retries on FAILED copies
/w:5 = 5 second WAIT before RETRY
/L = LIST Only Results of the command
/LOG:Your_LOG_08_24_2025_11_45_P.txt = Write Log to Text File

NOTE:

  • A FULL 5 TB drive takes about 14hrs to 24hrs to mirror for initial Backup.

DISCOVERY: (Better on my Windows system: No LOG, No Multi-Threading)

  • A Log File Prevents to see progress in Windows
  • The /mt (Multiple Thread) Option almost crashes the program on my computer

Recommended by Google A.I.
1.  Restart
2.  Check Connections
3.  chkdsk J:

Result:  Same Error

Solution:  

1.  Delete Offending Series Containing File
2.  Continue Robocopy command until Everything copied or further Errors Encountered
3.  On separate computer, preferrable not in use:
    * chkdsk X: /f /r /x
    
chkdsk: The command to check disk errors. 

X:: Replaced with the actual drive letter of your external HDD. 
/f: Fixes errors found on the disk. 
/r: Locates bad sectors and attempts to recover readable information from them; this also includes the functionality of /f. 
/x: Forces the volume to dismount if it is in use, which is useful if the scan is blocked. 
           
4.  Eventually Replace the Offending HDD (Hard Drive)

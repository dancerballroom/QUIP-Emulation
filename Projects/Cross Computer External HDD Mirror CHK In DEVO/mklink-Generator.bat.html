mklink-Generator.bat

Purpose: Generate a .bat file that creates all the Windows Virtual Directories that link to External HDDs

mklink-Generator.bat

@Echo Off
setlocal enableDelayedExpansion

REM mklink Generator 
REM by Lawrence W. Davies
REM
REM Creates Symbolic Links for Jellyfin Home Movie Server Management
REM EXAMPLE:
REM mklink /j "C:\JELLYFIN_HOME\HDD-6\DOCU-SERIES" "K:\DOCU-SERIES"

REM CONSTANTS

REM SET $VIRTUAL-HOME=D:\JELLYFIN_HOME\HDD-1\
REM SET $HDD-DIR-ROOT=E:\

IF "%~1" == "" GOTO :Help

SET $VIRTUAL-HOME=%1
SET $HDD-DIR-ROOT=%2

REM Prep Batch FILE
Echo @Echo Off 
REM > $BATCH-FILE
Echo.

REM # PSEUDOCODE
REM Loop through DIRS -> 
REM     $CMD = $CMD + $DIRS + " "
REM     $CMD = $CMD + $HDD-DIR-ROOT\DIRS
REM End Loop 

pushd !$HDD-DIR-ROOT!
for /d %%a in (*) do (
    SET $CMD=mklink /j "!$VIRTUAL-HOME!%%a" 
    SET $CMD=!$CMD! "!$HDD-DIR-ROOT!%%a"
    Echo !$CMD!    
)
popd
goto :ENDER
:Help
Echo Purpose: Create a mklink List
Echo Recommedation: Pipe list into a batch file and run it.
Echo.
Echo USAGE:  
Echo mklink-Generator.bat VIRTUAL-HOME DRIVE-LETTER 
Echo.
Echo Example: 
Echo mklink-Generator.bat (NO ARGS) for this HELP listing
Echo mklink-Generator.bat D:\MyVirtualDir\ F:\ (pipe to) BATCH-FILE  
Echo Run BATCH-FILE to create the Jellyfin Virtual Links.
Echo.
pause
:ENDER

Example:

All on 1-Line

C:\JELLYFIN_HOME\HDD-7>mklink-Generator.bat 
    C:\JELLYFIN_HOME\HDD-7\ 
    E:\ 
    > SeventhHDD-JellyFin-MkLink-Junction.bat

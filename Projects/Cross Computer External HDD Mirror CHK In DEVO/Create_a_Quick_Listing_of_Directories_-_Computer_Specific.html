Create a Quick Listing of Directories - Computer Specific

Given:

  • C:\JELLYFIN-HOME\HDD-1 Contains all the Sym-links for F:\ Drive
    • HDD-2 ... G:\
    • HDD-3 ... H:\
    • HDD-4 ... I:\
    • HDD-5 ... J:\
    • HDD-6 ... K:\
    • HDD-7 ... E:\
  • Changes based on Computer Drive Letter Allocation

See mklink-Generator.bat for Quick Sym-link Generation

Output:

  • !CNAME!_Seasons.txt 
  • !CNAME!_Movies.txt

Create_DIR_DB_Cur_Computer.bat

@Echo Off
setlocal enabledelayedexpansion
REM ********* Series/!CNAME!_SEASONS *************
REM This Batch File:
REM (1. Create File TEMP-ALL, 2. Read File & Replace Virtual HDD with Physical X:)
REM 1. Put Result in a File (Drive HDD-1 ONLY)
REM 2. Replace C:\Jellyfin Home\HDD-1 with F:, HDD-2 with G:, HDD-7 with E:, etc
Set /p CNAME="Enter the name of your computer : "

dir /B/AD/S HDD-1 | findstr /VI "metadata" | findstr /I "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-1','F:' > !CNAME!_SEASONS.txt
dir /B/AD/S HDD-2 | findstr /VI "metadata" | findstr /I "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-2','G:' >> !CNAME!_SEASONS.txt

POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-3','H:' >> !CNAME!_SEASONS.txt
dir /B/AD/S HDD-4 | findstr /VI "metadata" | findstr /I "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-4','I:' >> !CNAME!_SEASONS.txt
dir /B/AD/S HDD-5 | findstr /VI "metadata" | findstr /I "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-5','J:' >> !CNAME!_SEASONS.txt
dir /B/AD/S HDD-6 | findstr /VI "metadata" | findstr /I "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-6','K:' >> !CNAME!_SEASONS.txt
dir /B/AD/S HDD-7 | findstr /VI "metadata" | findstr /I "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-7','E:' >> !CNAME!_SEASONS.txt

REM ********* !CNAME!_MOVIES BOOKS MUSIC *************
dir /B/AD/S HDD-1 | findstr /VI "metadata" | findstr /VI "Series" | findstr /VI "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-1','F:' > !CNAME!_MOVIES.txt
dir /B/AD/S HDD-2 | findstr /VI "metadata" | findstr /VI "Series" | findstr /VI "Season" > TEMP-ALL.txt
POWERSHELL -Command (get-content TEMP-ALL.txt) -replace 'C:\\JELLYFIN_HOME\\HDD-2','G:' >> !CNAME!_MOVIES.txt

TXT2SRT-TAP

Purpose: Quickly Generate .SRT (Subtitle) file for Video
USAGE:  
Drag/Drop VIDEO_NAME.MP4 that has corresponding VIDEO_NAME.TXT
  • Launches Play of VIDEO_NAME.MP4
  • Press ENTER Twice to Start Meshing together Text and Time Signatures
    • Generates VIDEO_NAME_TIME-STAMP.SRT
    • Copies VIDEO_NAME.MP4 to VIDEO_NAME_TIME-STAMP.mp4
  • As Video Plays
    • PRESS ENTER each time you hear each line of TEXT
Example:
  •  TXT2SRT-TAP.bat (NO ARGS) for this HELP listing
  •  TXT2SRT-TAP.bat VIDEO_NAME.MP4  
    • Copies VIDEO_NAME.MP4 to VIDEO_NAME_TIME-STAMP.MP4
    • Creates VIDEO_NAME_TIME-STAMP.SRT
  •  The program terminates when the last lyric/TEXT/LINE is Reached.
Produces:
  •  Playable VIDEO_NAME_TIME-STAMP.MP4 and VIDEO_NAME_TIME-STAMP.SRT
  •  The final SRT will need adjustment using SUBTITLE EDIT

TXT2SRT-TAP.bat

@Echo Off
SETLOCAL enabledelayedexpansion

REM Show HELP if NOT MP4 DRAG/DROPPED
IF "%~1" == "" (
     CALL :Help
     EXIT
)

REM INITIALIZE VARIABLES
set /A elapsed=0
set /A cumelapsed=0
set lastloop_elapsed=00:00:00,000        REM STRING
set CUM_ELAPSED_TIME=!lastloop_elapsed!  REM STRING

REM count=How many times looped
set /A count=!count!+1

REM DEBUGGING
set /A TRUE=1
set /A FALSE=0

REM HIDE DEBUGGING
set /A DEBUG=!FALSE!

REM Start Video to Sync Subtitles
Start /b "" "%~d1%~p1%~n1%~x1"

REM The Great Loop
REM Do... Loop until Subtitles END
:BEGIN

set lastloop_elapsed=!CUM_ELAPSED_TIME!

REM Get the Current Time from the Computer
set STARTTIME=%TIME%

REM CRLF=CARRIAGE RETURN
REM BELOW the SET CRLF Leave 2 Lines Blank
SET CRLF=^


REM ABOVE This LINE Leave 2 Lines Blank

REM Only at the Beginning, HIT ENTER TWICE
REM Once to Load the START and Twice to Load the START and END
if !count! EQU 1 (
      SET /P wait="........[Hit Enter Twice to START]..........."
)

REM Hit ENTER ONCE
REM ROUND ROBIN START=END and Calculate NEW END 
if !count! GTR 1 (
      SET /P wait="........[Hit Enter Once to Continue].............."
)

REM Get the Current Time from the Computer
set ENDTIME=%TIME%

REM Time Functions
REM CALC (MATH) and FORMAT (STRING)
Call :CALC_START_TIME start                  
Call :CALC_END_TIME                            

Call :FORMAT_START_TIME                      
Call :FORMAT_END_TIME                        

Call :CALC_ELAPSED_TIME                      
CALL :FORMAT_ELAPSED_TIME CUM_ELAPSED_TIME   
                                             
if !DEBUG! EQU !TRUE! echo !CRLF!Last Statement

REM The Main Loop of the Entire Program
if !count! GEQ 3 (
     
     REM Run ONCE when count=3
     if !count! EQU 3 (
         set File="%~d1%~p1%~n1.txt"
         CALL :LOAD_TEXT output line_count !File!
         set SRT_NAME="%~d1%~p1%~n1-!start!.srt"
         copy "%~d1%~p1%~n1%~x1" "%~d1%~p1%~n1-!start!.mp4"
     )

     REM SUB_NUMBER=The Number of the Subtitle
     Set /A SUB_NUMBER=!SUB_NUMBER!+1
     Echo !CRLF!!SUB_NUMBER!

     REM WRITE TO THE NEW SUBTITLE FILE.SRT
     Echo !SUB_NUMBER! >> !SRT_NAME!

     Echo !lastloop_elapsed! --^> !CUM_ELAPSED_TIME!
     Echo !lastloop_elapsed! --^> !CUM_ELAPSED_TIME! >> !SRT_NAME!

     REM LOAD TEXT and Create SRT (Subtitle File)
     CALL :SHOW_LINE output SUB_NUMBER SRT_NAME line_count
     Echo.
     
     REM END PROGRAM when NO MORE LINES of TEXT
     If !SUB_NUMBER! EQU !line_count! (
          Echo End of Program
          Pause
          Exit
     )
)
Goto :BEGIN

if !DEBUG! EQU !TRUE! Echo. 
Pause
Exit /b

REM Show/Process Variable ARRAY with Variable Index
:SHOW_LINE
Echo Line Number: !SUB_NUMBER! of !line_count!
for %%i in (!SUB_NUMBER!) do (
  set element=!output[%%i]!
  echo !element!

REM WRITE TO SRT (Subtitle FILE)
  echo !element! >> !SRT_NAME!
  echo. >> !SRT_NAME!
)
Exit /b

REM Load the Subtitle Lines from the TEXT FILE
:LOAD_TEXT
     echo !File!
     set /a line_count=0
     set /a lines=0
     for /F "tokens=*" %%a in ('Type !File!') do (
         Set /a line_count=!line_count!+1
         Set output[!line_count!]=%%a
     )
     Echo Total Lines:      !line_count!

Exit /b

REM ONLY used for DEBUGGING
:LINE_NUMBER
     REM Purpose: DEBUGGING
     REM USAGE 
     REM CALL :LINE_NUMBER 20
     if !DEBUG! EQU !TRUE! powershell -Command "Write-Host '%1.. ' -NoNewline"
Exit /b

REM start=NUMBER
:CALC_START_TIME
REM MATHEFY start TIME
for /F "tokens=1-4 delims=:.," %%a in ("!STARTTIME!") do (
    set /A "start=(((%%a*60)+1%%b %% 100)*60+1%%c %% 100)*100+1%%d %% 1000"
) 
Exit /b

REM end=NUMBER
:CALC_END_TIME
REM MATHEFY end TIME
if !DEBUG! EQU !TRUE! powershell -Command "Write-Host '1.. ' -NoNewline"
for /F "tokens=1-4 delims=:.," %%a in ("!ENDTIME!") do (
    set /A "end=(((%%a*60)+1%%b %% 100)*60+1%%c %% 100)*100+1%%d %% 1000"
)
REM DEBUGGING
if !DEBUG! EQU !TRUE! powershell -Command "Write-Host '2.. ' -NoNewline"
if !DEBUG! EQU !TRUE! powershell -Command "Write-Host '3.. ' -NoNewline"
if !DEBUG! EQU !TRUE! Echo.
Exit /b

REM MATH
REM Part of the ROUND ROBIN Current/Previous Elapsed TIME
:CALC_ELAPSED_TIME
if defined elapsed ( set /A prevelapsed=!cumelapsed! ) else ( set /A prevelapsed=0 )

REM MAKE-UP FOR COMPUTER DELAY (Computer Dependent)
set /A ARBITRARY_DELAY_FUDGE=5

set /A elapsed=(!end! - !start!) + !ARBITRARY_DELAY_FUDGE!
set /A cumelapsed=!elapsed!+!prevelapsed!
Exit /b

REM STRING
:FORMAT_START_TIME 

set /A hh=start/(60*60*100), rest=start%%(60*60*100), mm=rest/(60*100), rest%%=60*100, ss=rest/100, cc=rest%%1000
if !hh! lss 10 set hh=0!hh!
if !mm! lss 10 set mm=0!mm!
if !ss! lss 10 set ss=0!ss!
if !cc! lss 10 set cc=0!cc!
set STARTTIME_FORMATTED=!hh!:!mm!:!ss!,!cc!

REM DEBUGGING
if !DEBUG! EQU !TRUE! Echo !CRLF!
if !DEBUG! EQU !TRUE! Echo START(Formatted): !CRLF!!STARTTIME_FORMATTED!
Exit /b

REM STRING
:FORMAT_END_TIME 
set /A ehh=end/(60*60*100), rest=end%%(60*60*100), emm=rest/(60*100), rest%%=60*100, ess=rest/100, ecc=rest%%1000
if !ehh! lss 10 set ehh=0!ehh!
if !emm! lss 10 set emm=0!emm!
if !ess! lss 10 set ess=0!ess!
if !ecc! lss 10 set ecc=0!ecc!
set ENDTIME_FORMATTED=!CRLF!!ehh!:!emm!:!ess!,!ecc!

REM DEBUGGING
if !DEBUG! EQU !TRUE! echo !CRLF!END(Formatted) !ENDTIME_FORMATTED!

Exit /b

REM STRING
:FORMAT_ELAPSED_TIME
set /A ethh=!elapsed!/(60*60*100), rest=!elapsed!%%(60*60*100), etmm=rest/(60*100), rest%%=60*100, etss=rest/100, etcc=rest%%1000
CALL :LINE_NUMBER 179
if !ethh! lss 10 set ethh=0!ethh!
if !etmm! lss 10 set etmm=0!etmm!
if !etss! lss 10 set etss=0!etss!
if !etcc! lss 10 set etcc=0!etcc!
CALL :LINE_NUMBER 184
set /A cethh=!cumelapsed!/(60*60*100), rest=!cumelapsed!%%(60*60*100), cetmm=rest/(60*100), rest%%=60*100, cetss=rest/100, cetcc=rest%%1000
CALL :LINE_NUMBER 186
if !cethh! lss 10 set cethh=0!cethh!
if !cetmm! lss 10 set cetmm=0!cetmm!
if !cetss! lss 10 set cetss=0!cetss!
if !cetcc! lss 10 set cetcc=0!cetcc!

set ELAPSED_TIME=!CRLF!!ethh!:!etmm!:!etss!,!etcc!
set CUM_ELAPSED_TIME=!cethh!:!cetmm!:!cetss!,!cetcc!

REM DEBUGGING
if !DEBUG! EQU !TRUE! echo !CRLF!Last Loop Elapsed: !lastloop_elapsed! 
if !DEBUG! EQU !TRUE! echo !CRLF!ELAPSED_TIME(Formatted) = !ELAPSED_TIME!!CRLF!
if !DEBUG! EQU !TRUE! echo Cumulated Time:           !CRLF!!CUM_ELAPSED_TIME!

set /A count=!count!+1
Exit /b

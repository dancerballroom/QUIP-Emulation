05-17-2006    Auto-DynDNS with StartRight

  • May. 17th, 2006 at 3:21 AM
Solved my problem of updating DynDNS after Restart. Now I can restart my computer remotely.

I found a program free called "DynDNS Client" at
http://www.lightdev.com/page/77.htm (Defunct) which only requires
you have installed the Sun Java JRE browser plugin, and a batchfile which runs:

java -jar DynDNSClient.jar

or

java -jar DynDNSClient.jar -noui

Of course you need to run the DynDNSClient.jar with the UI
first for configuration.

There were other utilities out there that seemed easier to use, but they were shareware, Yuck!

The last trick to get my system to startup in a fashion that would load each of my connection startup items was to install a small program
called StartRight at:

http://www.joejoesoft.com/sr.php (Defunct)

which replaces the Start/Programs/Start Up folder and allows you to configure which order to load things and how many seconds to pause after each load. This way I was able to restart my computer and within 2 minutes everythings was properly loaded and DynDNS updated.

Here is my order of loading my StartRight:
There are 2 categories: 1. Run Keys and 2. Start Up Folder

Under Run Keys:
1. 1/2 a second after each utility except 4 seconds after Anti-Vir
which is the last Run Key before loading the Start Up Folder

(Before my SBC connection to fail at least once, and
so the whole sequence of connecting with DynDNS without an
ip caused the java utility above to crash)

Under Start Up Folder
2. 10 seconds for SBC to connect with SBC.lnk to SBC.bat

(I have to have an IP before I run UpdateDynDNS)

3. 10 seconds to load CreateACard

(Big program)

4. 2 Seconds to Update DynDNS with my UpdateDynDNS.lnk to
UpdateDynDNS.bat

(It's quick. It just doesn't like not having an IP to work with)

5. 1/2 a Second to load NetworkAktiv AUTAPF Port Forwarder

(access to my second machine which works great now)

I had to experiment a couple of times with the timing. Too few seconds and it wouldn't work, Too many seconds and it would take forever to load.

A Few Run Keys I had to exclude due to out of order failures like: gmail notification. Unfortunately, the Run Keys can't be run after the Start Up Folder.
